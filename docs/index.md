# fukuemon.dev の設計の文書

fukuemon.dev の PRD、Design Doc、ADR を読むサイトである。
文書の原本は、リポジトリの `docs/` と、`docs/design/` のシンボリックリンクが指す Design Doc にある。

- [PRD](PRD.md): サイトが誰に何を提供するか
- [Design Doc](design/DesignDoc.md): サイトの全体像と、モジュールの責務と依存
- [ADR](adr/index.md): 決めたことと理由の一覧

コンポーネントのカタログは、このサイトに含めず、[design.fukuemon.dev](https://design.fukuemon.dev/) で公開している。
