# ADR の規則

ADR の書き方は、スキル write-design-docs に従う。  
次の 5 つは、このリポジトリの規則で、スキルの規則より優先する。

- 置き換えた ADR は、ファイルを消す。Status に置き換えたことを書いて、ファイルと索引の行を残す形にしない。消した ADR の本文は、Git の履歴で読める。
- 複数の ADR を 1 本にまとめるときは、新しい番号を取らない。まとめる ADR のうち、まとめた後の関心を題が表す ADR にまとめ、ほかの ADR は消す。
- 番号は振り直さない。消した ADR の番号は欠番にする。ほかの文書とコードのコメントが、番号で ADR を指すためである。
- ADR を消したときは、[索引](index.md#番号の対応) の「番号の対応」に、消した番号、判断、その判断を今決めている ADR の行を足す。コミット、issue、pull request に書いた番号から、今の ADR を探すためである。
- ADR のファイルを残したまま、判断の一部をほかの ADR に移したときは、索引の「番号の対応」の、判断の一部を移した ADR の表に、元の番号、移した判断、その判断を今決めている ADR の行を足す。

今有効な ADR の一覧は、[索引](index.md) にある。
