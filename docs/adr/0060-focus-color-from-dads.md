# ADR-0060: フォーカスの色を、DADS の値で持つ

## Status

ADR-0061 に置換

## Context

fukuemon.dev のデザインシステムのトークンの持ち方と、値の元を決める必要がある。

- 運営者は、和の感じの 3 つの案から、旧サイトに寄せる案を選んだ。DADS は、アクセシビリティ、タイポグラフィ、配色、レイアウトの指標と参考に留める。
- トークンを 3 つの層に分け、プリミティブトークンは fukuemon.dev の値を持つと決めている。
  - ADR-0024: [トークンを、fukuemon.dev の値のプリミティブトークン、セマンティックトークン、テーマ変数の 3 つの層にし、生成りの地と旧サイトの差し色で、角丸と影を使わない版面にする](0024-tokens-of-fukuemon-dev.md)

## Decision

- フォーカスの色は、DADS の `@digital-go-jp/design-tokens` 2.1.0 の値を使う。ファイルの冒頭に、出典の URL と MIT License の表示を残す。

## Considered Options

| 選択肢                                     | 強み                                | 弱み                               |
| ------------------------------------------ | ----------------------------------- | ---------------------------------- |
| **採用:** フォーカスの色を DADS の値で持つ | DADS のアクセシビリティの指標に沿う | 値を DADS の更新に合わせて写し直す |

## Consequences

### Positive

- フォーカスの表示が、DADS のアクセシビリティの指標に沿う。

### Negative

- 色のうち、フォーカスの色だけが DADS の値になる。
