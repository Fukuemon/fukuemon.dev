# ADR-0069: 詰めた木の行の中の名前の欄に内側の輪を引き、欄の行には輪を引かない

## Status

提案

## Context

ファイルの木（`FileTree`）は、作成と名前の変更を、木の行の中の名前の欄で行う（#163）。
欄にフォーカスがあるときの表示を決める必要がある。

- 詰めたペインの行は、墨の 2px の輪を要素の内側に引く（`focus-ring-inset`）。使う所は、`density="compact"` の `TreeView` の項目、`Tabs` のタブと閉じるボタン、`HttpExchangeList` の行に限っている。
  - ADR-0066: [コードを動かす画面の詰めたペインで、フォーカスの輪を要素の内側に引く](0066-inset-focus-ring-in-dense-panes.md)
- フォーカスの表示は、墨の 2px の 1 重の輪にすると決めている。
  - ADR-0061: [フォーカスの表示を、DADS の黄と黒の 2 重の表示から、墨の 2px の 1 重の輪にする](0061-sumi-focus-ring.md)
- 木の行は 24px で、上下に 2px の余白がある。名前の欄は 20px の高さで、1px の枠（`border-field`）を持つ。
- 欄のある行に内側の輪を引くと、輪の内側の線が欄の枠の上辺と下辺に接する。
  - 上下は、墨の 2px の輪と 1px の枠がつながり、3px の帯に見える。右は、6px をあけて縦の線が 2 本並ぶ。
  - 名前に誤りがあるときは、赤の枠が墨の輪の中に見え、二重の枠になる。
  - 1 重の輪にならず、ほかの行の輪とも見え方が違う。
- VS Code のエクスプローラーは、行の中の名前の欄のフォーカスを、欄の 1 本の枠で示し、行には輪を出さない（記憶による。実物で比べていない）。

## Decision

- 名前の欄に `focus-ring-inset` を付ける。輪は欄の 1px の枠に重ねて、欄の内側に引く。
- 欄を描いている `TreeView` の行には、フォーカスの輪を引かない。欄が、自分のフォーカスの表示を持つ。
- ADR-0066 の Decision の `focus-ring-inset` を使う所に、`FileTree` の名前の欄を足す。
- 理由は次のとおり。
  - 欄の枠と輪が重なるので、表示が 1 重の輪になる。
  - 輪の位置が、名前を打つ範囲と同じになる。
  - VS Code の行の中の欄と同じ表示で、利用者が見慣れている。

## Verification

カタログの `コンポーネント/Case/FileTree` を、Chromium の 1600x900 で開いて確認した。

- 単体テストで、名前の欄の輪が `outline: 2px solid` で `outline-offset: -2px` であり、欄の行に輪が無いことを確認した。
- 欄の文字は輪に欠けなかった。作成、名前の変更、名前の誤りの 3 つを、ライトとダークで静止画に撮って見た。

## Considered Options

| 選択肢                                       | 強み                                                         | 弱み                                                                                                |
| -------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| **採用:** 欄に内側の輪を引き、行には引かない | 1 重の輪になる。輪の位置が打つ範囲と同じ。VS Code と同じ表示 | 欄にフォーカスがある間は、誤りの赤の 1px の枠が輪に隠れる。`focus-ring-inset` を使う所が 1 つ増える |
| 行の輪を残し、欄を低くして輪との間を空ける   | ADR を変えない                                               | 欄が 16px になり、13px の文字が欠けるおそれがある                                                   |
| 今のまま、行の輪と欄の枠を並べる             | 変更が無い                                                   | 二重の枠に見え、1 重の輪にならない                                                                  |

## Consequences

### Positive

- 名前の欄のフォーカスを、ほかの要素と同じ 1 重の輪で示せる。

### Negative

- 欄にフォーカスがある間は、名前の誤りを赤の枠で示せない。誤りは、欄の下の印と理由の文と、`aria-invalid` で示す。
- `TreeView` の `editor` に欄を渡す側が、欄のフォーカスの表示を受け持つ。
