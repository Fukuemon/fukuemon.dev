# ADR-0080: 墨の絵と署名の SVG を、トップの HTML に入れず、最初の訪問のときだけ読み込む

## Status

提案

## Context

トップの墨の絵と署名の SVG を、どこから配るかを決める必要がある。

- ADR-0026 は、墨の絵を SVG の線にして HTML に置き、CSS の遷移で筆の順に描くと決めている。署名も SVG の `path` として置く。
  - ADR-0026: [トップの最初の訪問で水墨の門を描き、門をくぐった立体の庭にプロフィールを置く](0026-sumi-gate-and-garden-on-top.md)
- 墨の絵と署名を出すのは、最初の訪問のイントロの間だけである。2 回目以降の訪問と、庭を出さない訪問では、`display: none` のまま、画面に出ない。
- 墨の絵の SVG は、gzip で約 36 KB、署名の SVG は約 8 KB である。
- 2 回目以降の訪問のトップは、LCP が 2.5 秒以内で、Performance が 90 以上という要求の対象である。
- ADR-0026 の承認の条件は、要求を超えたら、ふつうの HTML を先に出し、「庭に入る」のボタンで庭を出す形に替えると決めている。
- トップの合否は、ADR-0078 の条件で測る。
  - ADR-0078: [トップの Lighthouse の合否を、Metal の GPU と simulate のスロットリングで 5 回測った中央値で判定する](0078-top-lighthouse-gpu-and-throttling.md)
- 墨の絵と署名の SVG の有無を、同じビルドから `<InkGate />` だけを外して比べた。
  - 条件は ADR-0078 と同じで、`pnpm run measure:top` を、有りと無しで 5 回ずつ、2 組測った。
  - HTML は、gzip で有りが 55,017 バイト、無しが 6,941 バイトだった。
  - 2 回目以降の訪問の Performance は、有りが 89 と 90、無しが 92 と 93 だった。LCP は、有りが 3150 ms と 3139 ms、無しが 2829 ms と 2827.5 ms だった。
  - 庭を出さない訪問（`--visit reduced-motion`）の Performance は、有りが 98、無しが 100 だった。LCP は、有りが 1801 ms、無しが 1501 ms だった。
  - 参考の `--throttling devtools` では、2 回目以降の Performance はどちらも 81 で、差が出なかった。
  - 測ったのは、墨の絵の有無だけを変えたビルドである。ほかの変更を入れたトップの値は測っていない。
- 最初の訪問は、LCP の要求の対象から除くと決めている。

## Decision

墨の絵と署名の SVG を、トップの HTML に入れない。最初の訪問のときだけ、別のファイルとして読み込む。

- 墨の絵と署名のファイルは、ビルドのときに `ink/` が作り、1 つのファイルとして `/_astro/` から配る。`stage/` には、場面のバンドルと同じく、URL だけを渡す。
- 最初の訪問のとき、head のスクリプトが、場面のバンドルと並べて、このファイルを読み込み、庭の墨の絵の置き場に挿す。線を描く遷移は、挿した時点から動く。
- head のスクリプトは、挿せたときに `html` の class `ink-ready` を付け、読み込みに失敗したときに `ink-failed` を付ける。class を読んで動くのは場面のバンドルである。
- 2 回目以降の訪問と、庭を出さない訪問では、墨の絵と署名のファイルを読み込まない。HTML にも入れない。
- 墨の絵と署名のファイルが読み込めなかったときは、ふつうのページに戻す。場面が動き出した後の片付けは、場面のバンドルが持つので、場面のバンドルが `ink-failed` を読んで戻す。
- 場面の準備を 6 秒で打ち切る決定は、最初の訪問では、`scene-ready` と `ink-ready` の両方が 6 秒で揃わなければ、ふつうのページに戻すことにする。2 回目以降の訪問は、今のままにする。`scene-ready` の意味は変えない。
- ふつうのページの帯に止まった水墨の絵を置く決定は、置き換える。ふつうのページには、墨の絵を置かない。今のトップも置いていない。
- 墨の線と署名の遷移が終わるのを待ってから色を差す決定は、変えない。場面のバンドルは、`ink-ready` が付いてから、遷移を集めて待つ。時刻の下限は、`ink-ready` を付けた時刻から 5000 ms にする。
- ADR-0026 の、墨の絵の描き方（SVG の線、筆の順、立体の配置と同じ位置、署名の `path`）は、変えない。

理由は、LCP が要求に届かない 2 回目以降の訪問に、使わない約 48 KB（gzip）を配らないためである。
測定では、墨の絵と署名を HTML から外すと、2 回目以降の LCP が約 0.32 秒短く、Performance が約 3 点高かった。

## 承認の条件

実装の中で、次を確認する。

- 最初の訪問のイントロが、今と同じ筆の順で終わり、署名と墨の絵が、色を差すまでに描き終わる。
- 墨の絵と署名のファイルの応答を遅らせたとき、場面の準備を 6 秒で打ち切る動きで、ふつうのページに戻る。
- 2 回目以降の訪問と、庭を出さない訪問の HTML に、イントロの墨の絵と署名（`.ink-gate` の中）の SVG が無い。ヘッダーのロゴの署名は、全てのページの HTML に残る。
- 墨の絵と署名のファイルが、場面の準備より後に届いても、線を描き終わってから色を差す。
- `stage/` と `ink/` の間の import の向きの規則を、Design Doc と Oxlint に足す。
- 外した後の 2 回目以降の訪問のトップを、ADR-0078 の条件で測り直し、値を記録する。要求を満たさないときの扱いは、ADR-0026 の承認の条件による。

承認の後に直す文書は、次のとおり。

- ADR-0026 の、墨の絵と署名を HTML に置く記述と、ふつうのページの帯に止まった水墨の絵を置く記述。
- `docs/adr/index.md` の「番号の対応」に、ADR-0026 から ADR-0080 へ移した 2 つの判断を足す。
- `packages/ui/src/art/DesignDoc.md` と `apps/web/src/features/top-garden/DesignDoc.md` の、墨の絵を HTML に置く記述。

## Considered Options

| ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **採用:** 墨の絵と署名の SVG を HTML に入れず、最初の訪問のときだけ別のファイルで読み込む | 2 回目以降の HTML が、gzip で約 48 KB 小さくなる。測定で、LCP が約 0.32 秒短く、Performance が約 3 点高かった。庭を出さない訪問にも、配らない | 最初の訪問で、墨の線を描き始めるのが、ファイルが届くまで遅れる。読み込みが 1 つ増え、失敗する場面が 1 つ増える          |
| 今のまま、HTML に入れる                                                                   | 最初の訪問で、HTML と一緒に届き、線を描き始めるのが遅れない。実装が要らない                                                                   | 2 回目以降の Performance の中央値が 89〜90 で、要求の 90 と同じ値になる。LCP が約 0.32 秒延びる                         |
| ふつうの HTML を先に出し、「庭に入る」のボタンで庭を出す形に替える                        | ADR-0026 の承認の条件に沿う。LCP の要求を満たしやすい                                                                                         | イントロと、庭がすぐ出る動きが無くなる。ADR-0026 の演出の決定を置き換える                                               |
| 墨の絵と署名の SVG を、HTML に残して小さくする                                            | 読み込みが増えない                                                                                                                            | gzip で約 48 KB（測定した HTML の差）を、使わない訪問にも配る。線を減らすと、絵が変わる。小さくした後の値は測っていない |

## Consequences

### Positive

- 2 回目以降の訪問と、庭を出さない訪問の HTML が小さくなる。
- 2 回目以降の LCP と Performance の要求に、近づく。

### Negative

- 最初の訪問で、墨の線を描き始める時刻が、ファイルが届くまで遅れる。
- 墨の絵と署名のファイルの読み込みの失敗を、扱う必要がある。
- 外しても、測定では庭を出す訪問の LCP が 2.83 秒で、この変更だけでは要求の 2.5 秒以内に届かない見込みである。測り直した値が届かないときの扱いは、ADR-0026 の承認の条件による。この ADR では決めない。
