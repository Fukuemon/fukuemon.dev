# ADR-0082: 庭を出さないときのトップの画面全体に、霞が流れる薄墨の絵を CSS の mask で敷く

## Status

提案

## Context

庭を出さないときのトップ（ふつうのページ）に、墨の絵を置くかと、置くならどう配信し、どう動かすかを決める必要がある。

- ADR-0026 は、庭を出さない訪問者にも同じ画風の絵を出すと決めていたが、ADR-0080 がその判断を移し、ふつうのページには墨の絵を置かないと決めた。
  - ADR-0026: [トップの最初の訪問で水墨の門を描き、門をくぐった立体の庭にプロフィールを置く](0026-sumi-gate-and-garden-on-top.md)
  - ADR-0080: [墨の絵と署名の SVG を、トップの HTML に入れず、最初の訪問のときだけ読み込む](0080-ink-gate-svg-loaded-on-first-visit.md)
- ADR-0080 が墨の絵を置かないとした理由は、墨の絵を使わない訪問に、墨の絵と署名の SVG（gzip で約 44 KB）を配信しないためである。HTML に入れると、庭を出す 2 回目以降の訪問にも配信される。
- 運営者は、2026-11-15 に、庭を出さないときのトップに墨の絵を置くと決めた。ADR-0026 が決めていたプロフィールの帯に収める形をやめ、画面全体の背景として動きのある絵にする。
- issue #61 に実装の基準として添えた試作の静止画の 3 枚は、どれも絵が無いふつうのページである。背景の絵の配置と色の基準は無い。
- 庭を出さないのは、次の 4 つのとき。
  - 表示の設定で庭をオフにしたとき
  - 表示の設定を保存せずに、OS で動きを減らす設定にしているとき
  - JavaScript が動かないとき
  - WebGL が使えないとき
- `head` の inline script が、ブラウザが本文を描く前に、庭を出すかを決める。庭を出すときは、`html` に class `stage-on` を付ける。
- 全てのページの `head` の inline script が、表示の設定のアニメーションを `html` の `data-motion` に `on` か `off` で書く。保存していないときは、OS で動きを減らす設定なら `off` にする。JavaScript が動かない環境では、`data-motion` が付かない。
- 今の墨の絵の SVG では、ページの CSS（`ink/InkGate.astro`）が、class と id を参照して、線の色と、かすれ（`feTurbulence`）とにじみの filter を当てている。mask の画像には、ページの CSS は適用されない。
- 墨の線の色は、文字の色のトークン（`--fd-color-text`）で、テーマで替わる。サイトのテーマは OS の設定に従う。
- 全体の Design Doc の動きの規則は、位置を動かさないことと、5 秒を超える動きを 5 秒以内に止めることを決めている。
- ADR-0028 は、挿絵 kasumi の霞の帯を横に動かさないと決めている。位置を動かさない規則の例外を、トップの庭だけに保つためである。
  - ADR-0028: [操作できる要素と重なる面の角を 4px で丸め、ボタンと入力欄にステッチを引き、重なる面にずらした影を付け、罫を引く動きを筆の線にする](0028-radius-shadow-and-brush-motion.md)
- デザインシステムの規則は、色と動きをテーマ変数のユーティリティだけで書き（`COLOR-TOKEN`、`MOTION-TOKEN`）、繰り返す動きを処理中の印だけにすると決めている。
- サイトのヘッダーは背景を持たず、下に罫を引いている。幅が狭いと折り返して高くなる。
- ADR-0026 は、庭の舞う物を 5 秒の規則の例外にし、表示の設定のアニメーションのスイッチを、WCAG 2.2.2 が求める止める手段にしている。
- 庭を出す 2 回目以降の訪問と、庭を出さない訪問は、LCP が 2.5 秒以内で Performance が 90 以上という要求の対象である。測り方は ADR-0078 の条件に従う。
  - ADR-0078: [トップの Lighthouse の合否を、Metal の GPU と simulate のスロットリングで 5 回測った中央値で判定する](0078-top-lighthouse-gpu-and-throttling.md)
- Content-Security-Policy は `frame-ancestors` だけを指定している。

## Decision

庭を出さないときのトップの画面全体に、イントロと同じ線の墨の絵を、濃さ 16% で敷く。
絵は HTML に入れず、別の SVG のファイルにする。
その SVG を CSS の `mask-image` で背景の要素に掛け、文字の色のトークンで塗る。
絵の上に紙の色の霞を重ね、霞を左右にゆっくり流す。
この判断は、ADR-0080 の「ふつうのページには、墨の絵を置かない」と、ADR-0026 の同じ記述を置き換える。
また、ADR-0028 の「位置を動かさない規則の例外を、トップの庭だけに保つ」を、この背景の霞について置き換える。
kasumi の霞の帯を横に動かさない判断は、そのまま残す。
置き換えは、ADR-0080 が ADR-0026 に対して行った形にそろえる。
古い ADR の記述に「（ADR-0082）」と書き添え、索引の「判断の一部を移した ADR」の表に載せる。

- ファイル
  - `apps/web/src/features/top-garden/ink/` の生成のコードが、イントロの墨の絵の SVG から、テーマの色を持たない mask 用の SVG を作る。mask の形を決める線の色（黒）と filter は、SVG の中の `style` に持つ。
  - 生成した SVG は、リポジトリにコミットする。ユニットテストが、生成のコードの出力とファイルが同じであることを確認する。
  - ビルドが、内容のハッシュを入れたファイル名で `/_astro/` に出力する。
  - 生成する SVG には、`<script>`、`<foreignObject>`、`on` で始まる属性、`href` を出さない。同じ origin の URL を直接開くと、SVG は文書として描かれるためである。
  - SVG は gzip で 30 KiB 以下にする。
- 背景の要素
  - 背景の要素と CSS は、`ink/` のコンポーネントに置き、トップのページが直接 import する。SVG の URL は、CSS に相対パスの `url()` で書き、ビルドがハッシュの付いた URL に書き換える。
  - 背景の要素は、画面に固定し、本文の後ろに置く。`html.stage-on` のときは `display: none` にする。
  - 塗りは、`@supports (mask-image: url(""))` の中でだけ当てる。`mask-image` に対応しないブラウザで、画面を塗りつぶさないためである。
  - 庭を出さないときは、サイトのヘッダーに紙の色の背景を敷き、絵をヘッダーの下の罫で切る。絵をヘッダーのロゴと罫に重ねないためである。ヘッダーが折り返して高くなっても、ヘッダーの高さのまま隠れる。
  - 背景の要素は `aria-hidden="true"` にして読み上げから外す。
  - ハイコントラスト（`forced-colors: active`）では、背景を出さない。背景の絵は装飾であるためである。
- 濃さ
  - 濃さは 16% にする。トップで使う文字の色（本文、補足、リンク）が、ライトとダークの両方で、背景の最も濃い所に対してコントラスト 4.5:1 以上を保つためである。
  - 16% のときの最も低い値は、ライトのリンクの色の 4.71:1 である。20% では、ライトのリンクの色が 4.27:1 になる。
  - 霞は紙の色なので、重なった所の文字のコントラストは下がらない。
- 動き
  - 霞の 3 つの要素を、48 秒と 64 秒で左右に往復させる。CSS のアニメーションだけで動かし、動きのための JavaScript は配らない。
  - `html` の `data-motion` が `on` のときだけ動かす。表示の設定でアニメーションをオフにしたとき、表示の設定を保存せずに OS で動きを減らす設定にしているとき、JavaScript が動かない環境では、止まった絵になる。
  - 背景の霞の動きは、5 秒を超える動きを 5 秒以内に止める規則の例外にする。
    - 止める手段は、ADR-0026 の舞う物と同じく、表示の設定のアニメーションのスイッチにし、背景に止めるボタンを足さない。
    - 出典: [Understanding SC 2.2.2: Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)
  - 霞の位置が動くので、位置を動かさない規則の例外にする。
    - 霞は本文の後ろにあり、本文と罫の位置は動かないためである。
    - 位置の規則の例外は、トップの庭とこの背景の 2 つになる。
  - 霞の濃さと動きは、デザインシステムの `COLOR-TOKEN` と `MOTION-TOKEN` の規則と、繰り返す動きを処理中の印だけにする規則の例外にする。
    - `InkBackground.astro` の `<style>` に、濃さと `animation` を直に書く。値はこの背景だけのもので、ほかの画面では使わないためである。
    - 霞は `html[data-motion="on"]` のセレクタの中でだけ動かす。画面のコードに設定ごとの条件を書かない `MOTION-REDUCE` の規則の例外である。JavaScript が動かないときに霞を止めるには、`data-motion` が付かないことを条件にする必要があるためである。
    - 表示の設定でアニメーションをオフにしたときは、テーマ変数のファイルの止め方でも止まり、ほかの動きと一緒に止まる。
- 配信
  - HTML に入れるのは、背景の要素と CSS だけにする。庭を出す訪問では背景が `display: none` なので、SVG のファイルを取得しない。
  - 庭を止めてふつうのページに戻ったときは、ブラウザは背景を出した時点で SVG のファイルを取得する。
  - Content-Security-Policy は、この取得を止めない。後で CSP に `img-src` を足すときは、同じ origin を許す。
- 性能の差の上限
  - 背景の有りと無しの差は、LCP で 50 ms 以内とし、有りの Performance を無しより下げない。庭を出す訪問と庭を出さない訪問の両方で、ADR-0078 の条件で測る。

理由は、JavaScript が動かない環境でも止まった絵を出せ、庭を出す訪問に SVG のファイルを取得させないためである。
`mask-image` は、塗りをトークンの色にできるので、SVG に色の値を書かずにテーマに合わせられる。
画面全体に敷いても、薄墨にすれば、文の後ろに和紙の面を足さずに読みやすさを保てる。

## 承認の条件

- 背景の有りと無しを、ADR-0078 の条件で、庭を出す訪問（引数なしの `pnpm run measure:top`）と庭を出さない訪問（`--visit reduced-motion`）で測る。
  - 5 回の測定を 1 組とし、訪問と背景の有無の組み合わせごとに 2 組を測る。
  - HTML の gzip のバイト数を、有りと無しで記録する。
  - 差が、性能の差の上限を超えないことを確認する。超えたときは、実装を止めて扱いを決め直す。
  - 背景の有りのレポートで、`largest-contentful-paint-element` が本文の要素のままであることを確認する。
- Firefox でも、庭を出す訪問で背景の SVG を取得しないことを確認する。取得するときは、Firefox だけ取得を許す。Firefox の庭を出す訪問は、ADR-0078 の測定の対象の外で、影響を測れないためである。

どちらの条件も、Verification の結果で満たした。

承認の後に直す文書は、次のとおり。

- ADR-0080 の、ふつうのページに墨の絵を置かない記述。
- ADR-0026 の、ふつうのページに墨の絵を置かない記述と、見た目の回帰の対象（ふつうのページと止めた庭の絵）の記述。
- ADR-0028 の Decision の「挿絵」の、位置を動かさない規則の例外をトップの庭だけに保つ記述。
- `docs/adr/index.md` の移した判断の表。ADR-0026 の行の移した先を直し、ADR-0080 と ADR-0028 から移した判断の行を足す。
- `docs/design/DesignDoc.md` の「動き」に、背景の霞の例外。
- `packages/ui/DesignDoc.md` の「動きの長さ」の、繰り返す動きを処理中の印だけにする記述と、「動きを付けない所」の、位置と配置を動かさない記述に、背景の霞の例外。
- `packages/ui/DESIGN.md` の `COLOR-TOKEN`、`MOTION-TOKEN`、`MOTION-REDUCE` に、背景の例外。

## Verification

- 背景を入れる要素が `display: none` のとき、別の SVG のファイルを取得するかを、出し方ごとに、最小のページで確認した。最小のページでは、帯の形の要素で確認した。
  - Playwright の Chromium と WebKit で、同じスクリプトで、ブラウザのエンジンだけを替えた。最小のページの確認では、Firefox は確認していない。
  - `<img>` は取得し、`<img loading="lazy">`、CSS の `background-image`、CSS の `mask-image` は取得しなかった。`background-image` は、`html:not(.stage-on)` のセレクタで掛けた条件で確認した。
- 実装したトップで、次を E2E で確認した。
  - 庭を出す訪問で、背景の SVG の取得が 0 件で、背景が出ない。
  - 表示の設定でアニメーションをオフにしたとき、表示の設定を保存せずに OS で動きを減らす設定にしているとき、JavaScript が動かないときに、霞が動かない。
  - ライトとダークの止まった背景の絵が、Linux の Chromium で、かすれの filter ごと描かれる。
- 実装したトップを Firefox 157 で開き、庭を出す訪問で背景の SVG の取得が 0 件で、アニメーションのオフと OS の動きを減らす設定で霞が動かないことを確認した。かすれの filter も描かれた。
- 背景の有りと無しを、ADR-0078 の条件で、5 回の測定を 1 組として、2 組ずつ測った。
  - HTML の gzip は、有りが 10,404 バイト、無しが 10,328 バイトで、差は 76 バイトだった。
  - LCP の要素は、全ての回で本文の段落（`section.max-w-body > p.mb-4`）だった。
  - 全ての組で、`lcpIsFcp` で除いた回は 0 回だった。
  - 組ごとの結果。

  | 訪問                | 組  | 有りの Performance | 無しの Performance | 有りの LCP | 無しの LCP | LCP の差 |
  | ------------------- | --- | ------------------ | ------------------ | ---------- | ---------- | -------- |
  | 庭を出す 2 回目以降 | 1   | 95                 | 95                 | 2380 ms    | 2393 ms    | -13 ms   |
  | 庭を出す 2 回目以降 | 2   | 95                 | 95                 | 2386 ms    | 2383 ms    | +3 ms    |
  | 庭を出さない        | 1   | 100                | 100                | 1051 ms    | 1052 ms    | -1 ms    |
  | 庭を出さない        | 2   | 100                | 100                | 1052 ms    | 1052 ms    | 0 ms     |
  - どの組も、LCP の差は 50 ms 以内で、有りの Performance は無しより低くなかった。

## Consequences

### Positive

- 庭を出さない訪問者にも、庭と同じ画風の絵を出せる。
- 庭を出す訪問では、SVG のファイルを取得しない。
- 止め方が、庭の舞う物と同じ表示の設定のスイッチにそろう。

### Negative

- 動きの規則の例外が、庭のほかに増える（5 秒の規則、位置の規則、`COLOR-TOKEN`、`MOTION-TOKEN`、`MOTION-REDUCE`、繰り返す動きの規則）。
- 庭を出す訪問の HTML も、背景の要素と CSS の分だけ増える。
- 庭を出さない訪問では、読み込みが 1 つ増える。
- 背景だけを止めて、ほかの動きを残すことはできない。
- 庭を止めてふつうのページに戻ったときは、背景が後から出る。背景は本文の後ろに固定するので、本文の位置はずれない。
