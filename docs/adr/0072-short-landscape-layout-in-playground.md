# ADR-0072: 高さが 500px 未満の画面では、幅が広くても、コードを動かす画面を狭い配置にし、ペインを左の縦のタブで切り替える

## Status

提案

## Context

スマートフォンを横に向けたときの、コードを動かす画面の配置の条件を決める必要がある。

- テーマ変数は、Tailwind のデフォルトのブレークポイントを消し、ここに置いた名前だけをユーティリティにすると決めている。
  - ADR-0024: [トークンを、fukuemon.dev の値のプリミティブトークン、セマンティックトークン、テーマ変数の 3 つの層にし、生成りの地と旧サイトの差し色で、角丸と影を使わない版面にする](0024-tokens-of-fukuemon-dev.md)
- テーマ変数に置いたブレークポイントは、幅 48rem の `md` だけである（`packages/ui/design/tokens.md` の「ブレークポイントは、DADS の設定の例の 1 つ（48rem）だけを置く」）。
- 指で押す端末では、押せる領域と、行と帯の高さを 44px にする提案がある。この ADR は ADR-0071 を前提にするので、承認は ADR-0071 を先にする。
  - ADR-0071: [指で押す端末では、コードを動かす画面の押せる領域を 44px にし、iOS の入力時の拡大を viewport の指定で止める](0071-touch-targets-and-ios-zoom-in-playground.md)
- 375×812 の端末を横に向けると、幅 812px、高さ 375px になる。幅だけで分けると、ファイルの木、エディタ、プレビュー、端末を並べる PC の配置になる。
- PC の配置で高さ 375px に端末とエディタを上下に並べると、44px の帯と見出しを除いたエディタの高さは、数行になる。
- 記事に埋めた実行環境は iframe の中のページで、メディアクエリの幅と高さは、iframe の幅と高さで決まる。記事の段の幅（640px）は 48rem より狭い。
- 記事に埋める iframe の高さは、記事の形式の設計が決める。まだ決めていない。

## Decision

コードを動かす画面は、幅が 48rem 未満か、高さが 500px 未満のときに、狭い配置にする。

- 狭い配置では、ファイルの木を左のドロワーで出し、エディタ、端末、プレビューのペインを 1 つずつ切り替えて出す。
  - 縦の画面（幅が 48rem 未満で、高さが 500px 以上）では、ペインを下のタブで切り替える。
  - 高さが 500px 未満のときは、幅にかかわらず、下のタブの代わりに、左に縦のタブを置き、選んだペインを右に広げる。下に帯を置くと、ペインの高さがさらに減るためである。
  - 記事に埋めた実行環境では、下のタブの代わりに、枠の上のタブでペインを切り替える。高さが 500px 未満の iframe では、ほかの画面と同じく左の縦のタブにする。
- テーマ変数に、高さの条件の custom variant を 1 つ置く（`short`、`(max-height: 499.98px)`）。幅の `md` と並べて使い、コードを動かす画面の外では使わない。
- 500px は、横に向けたスマートフォンを含み、PC のブラウザの窓を含まないように選んだ値である。
  - 横に向けたスマートフォンの高さは、端末の短い辺（多くは 320〜430 CSS px）からブラウザの帯を引いた値で、430px を超えない。
  - PC のブラウザの窓の高さは、多くは 600px 以上である見込みで、測っていない（未確認）。

## 承認の条件

- 実機の iPhone の Safari を横に向け、ツールのページが左の縦のタブの配置になり、選んだペインが画面の高さいっぱいに出ること。
- PC の Chrome の窓の高さを 500px 未満にしたとき、左の縦のタブの配置になり、500px 以上に戻すと PC の配置に戻ること。

## Considered Options

| 選択肢                                                                  | 強み                               | 弱み                                                                   |
| ----------------------------------------------------------------------- | ---------------------------------- | ---------------------------------------------------------------------- |
| **採用:** 高さ 500px 未満でも狭い配置にし、横向きでは縦のタブを左に置く | 横向きでもエディタの高さを保てる   | 高さの条件の variant が 1 つ増える                                     |
| 幅だけで分ける                                                          | ブレークポイントが増えない         | 横向きで、4 つのペインが高さ 375px に並び、エディタが数行になる        |
| 横向きでも下のタブにする                                                | 縦向きと同じコンポーネントで組める | 下の帯の分だけ、ペインの高さが減る                                     |
| 横向きを `orientation: landscape` で分ける                              | 向きの名前のとおりに読める         | 低い窓の PC のブラウザと、高さの十分な横向きのタブレットを分けられない |

## Consequences

### Positive

- 横に向けたスマートフォンでも、エディタと端末を 1 つずつ広く使える。

### Negative

- コードを動かす画面の配置が、縦の狭い配置、横の狭い配置、PC の配置の 3 つになり、撮って確認する幅と高さが増える。
- 高さの条件の variant は、テーマ変数のブレークポイントを `md` だけにした決定の例外になる。
