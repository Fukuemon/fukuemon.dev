# ADR-0082: 庭を出さないときのトップの帯に、墨の絵を CSS の mask で置く

## Status

提案

## Context

庭を出さないときのトップ（ふつうのページ）の帯に、墨の絵を置くかと、置くならどう配信するかを決める必要がある。

- ADR-0026 は、庭を出さない訪問者にも同じ画風の絵を出すと決めていたが、ADR-0080 がその判断を移し、ふつうのページには墨の絵を置かないと決めた。今のトップには、帯の要素も帯の絵も無い。
  - ADR-0026: [トップの最初の訪問で水墨の門を描き、門をくぐった立体の庭にプロフィールを置く](0026-sumi-gate-and-garden-on-top.md)
  - ADR-0080: [墨の絵と署名の SVG を、トップの HTML に入れず、最初の訪問のときだけ読み込む](0080-ink-gate-svg-loaded-on-first-visit.md)
- ADR-0080 が墨の絵を置かないとした理由は、使わない訪問に墨の絵と署名の SVG（gzip で約 44 KB）を配信しないためである。HTML に入れると、庭を出す 2 回目以降の訪問にも配信される。
  - ADR-0080 の測定では、庭を出さない訪問（`--visit reduced-motion`）の LCP は、墨の絵と署名を HTML に入れると 1801 ms、入れないと 1501 ms だった。Performance は 98 と 100 だった。
- 運営者は、2026-11-13 に、帯の絵を背景として動き続ける形にすると決めた。止めたことは `localStorage` に覚える。
- 庭を出さないときは、次の 4 つ。
  - 表示の設定で庭をオフにしたとき
  - 表示の設定を保存せずに、OS で動きを減らす設定にしているとき
  - JavaScript が動かない環境
  - WebGL が使えない環境
- JavaScript が動かない環境でも、止まった絵を出す必要がある。
- 庭を出すかは、`head` の inline script が本文を描く前に決め、庭を出すときは `html` に class `stage-on` を付ける。
- 墨の線の色は、文字の色のトークン（`--fd-color-text`）で、テーマで替わる。サイトのテーマは OS の設定に従う。版画風の挿絵は、SVG に色の値を書かない。
- 庭を出す 2 回目以降の訪問と、庭を出さないトップは、LCP が 2.5 秒以内で、Performance が 90 以上という要求の対象で、ADR-0078 の条件で測る。
  - ADR-0078: [トップの Lighthouse の合否を、Metal の GPU と simulate のスロットリングで 5 回測った中央値で判定する](0078-top-lighthouse-gpu-and-throttling.md)
- 帯の動きと止めるボタンは、動きの案を運営者が選んだ後に、別の ADR で決める。この ADR は、止まった絵の置き方と配信だけを扱う。

## Decision

庭を出さないときのトップの帯に、止まった墨の絵を置く。
絵は、HTML に入れず、別の SVG のファイルを CSS の `mask-image` で帯の要素に掛け、塗りをトークンの色にする。
この判断は、ADR-0080 の「ふつうのページには、墨の絵を置かない」と、ADR-0026 の同じ記述を置き換える。

- ファイル
  - ビルドのときに `ink/` が、リポジトリの中の入力だけから、帯の高さに収まる配置の SVG を作る。`/_astro/` から、内容のハッシュを入れたファイル名で配信する。
  - SVG に色の値を書かない。墨の線の濃さは alpha で持つ。
  - 生成する SVG には、`<script>`、`<foreignObject>`、`on` で始まる属性、外を参照する `href` を出さない。同じ origin の URL を直接開くと、SVG は文書として描かれるためである。
  - 帯の配置は `ink/` の中に置く。墨の絵と場面が共有する `layout.ts` は、読むだけにする。
- 帯の要素
  - 帯の要素と CSS は、`ink/` のコンポーネントに置き、トップのページが直接 import する。SVG の URL は、`stage/` を経由せずに渡す。
  - 帯の要素は、`html.stage-on` のとき `display: none` にする。
  - 塗りは、`@supports (mask-image: url(""))` の中でだけ、帯の要素の `background-color` に `--fd-color-text` を当てる。`mask-image` に対応しないブラウザで、帯を塗りつぶさないためである。
  - 帯の要素は `aria-hidden="true"` にして読み上げから外す。
- 配信
  - HTML に入れるのは、帯の要素と、帯の CSS だけにする。庭を出す訪問では帯が `display: none` なので、SVG のファイルを取得しない。
  - 場面の読み込みに失敗してふつうのページに戻ったときは、帯を出した時点で取得する。
  - SVG の URL は、帯の CSS に相対パスの `url()` で書き、ビルドがハッシュの付いた URL に書き換える。実行時に URL の文字列を組み立てない。
  - Content-Security-Policy は `frame-ancestors` だけで、この取得を止めない。後で絞るときは、`img-src` に同じ origin を許す。

理由は、JavaScript が動かない環境でも止まった絵を出せ、庭を出す訪問に SVG のファイルを取得させないためである。
`mask-image` は、塗りをトークンの色にできるので、SVG に色の値を書かずにテーマに合わせられる。
`mask-image` の画像は LCP の候補にならない見込みで、LCP は今と同じく本文の要素で決まる見込みである（未確認）。

## Verification

帯の中が `display: none` のとき、別の SVG のファイルを取得するかを、出し方ごとに確認した。

- 条件は、Playwright の Chromium と WebKit で、同じスクリプトのエンジンだけを替えた。Firefox は確認していない。
- ページは、`html.stage-on .band { display: none; }` だけを持つ最小のページで、実際のビルドでは確認していない。
- `background-image` は、`html:not(.stage-on)` のセレクタで掛けた条件で確認した。`display: none` だけで取得しないかは確認していない。

| 出し方                    | 帯が `display: none` | 帯を出す |
| ------------------------- | -------------------- | -------- |
| `<img>`                   | 取得する             | 取得する |
| `<img loading="lazy">`    | 取得しない           | 取得する |
| CSS の `background-image` | 取得しない           | 取得する |
| CSS の `mask-image`       | 取得しない           | 取得する |

## 承認の条件

実装の中で、次を確認する。

- 庭を出す訪問で、帯の SVG のファイルの取得が 0 件である。Firefox が取得するときは、Firefox だけ取得を許す。Firefox の庭を出す訪問は、ADR-0078 の測定の対象の外で、影響を測れないためである。
- 庭を出す訪問を引数なしの `pnpm run measure:top` で、庭を出さない訪問を `--visit reduced-motion` で、帯の有りと無しを 2 組ずつ測る。
  - HTML の gzip のバイト数を、有りと無しで記録する。
  - 帯の有りが要求を満たさないとき、または有りと無しの差が運営者の決めた許容を超えるときは、実装を止めて扱いを決め直す。
  - 両方の訪問の `--throttling devtools` の値を、参考に添える。
  - 帯の有りのレポートで、`largest-contentful-paint-element` が本文の要素のままであることを確認する。
- 帯の SVG の gzip のサイズの上限を、測定から決め、生成器のユニットテストで確認する。
- `--cpu 4` 相当で、帯を出した読み込みと幅の変更を Performance パネルで記録し、mask の中の filter の raster と paint の時間を残す。長いときは、かすれを生成のときに `path` の形にする案と比べる。
- 見た目の回帰のテストに、止まった帯の絵のライトとダークを足し、通る。
- JavaScript が動かない環境と、動きを減らす設定で、止まった絵が出る。
- 読み上げで、帯の絵が読まれない。
- ビルドのときに `ink/` が作る SVG を、帯の CSS から相対パスで参照できる。できないときは、URL を CSS のカスタムプロパティに文字列として渡し、`)` と引用符で宣言の外に出ないことをテストで確認する。
- 生成する SVG に、`<script>`、`<foreignObject>`、`on` で始まる属性、外を参照する `href` が無いことを、生成器のテストで確認する。
- `feTurbulence` のかすれの filter が、`mask-image` の SVG の中で描かれる。Chromium、WebKit、Firefox の静止画を並べて、運営者が見る。

承認の後に直す文書は、次のとおり。

- ADR-0080 の、ふつうのページに墨の絵を置かない記述。
- ADR-0026 の、ふつうのページに墨の絵を置かない記述と、見た目の回帰の対象（ふつうのページと止めた庭の絵）の記述。
- `docs/adr/index.md` の「挿絵とトップの演出」の表と、移した判断の表の ADR-0026 の行の移した先。
- `packages/ui/src/art/DesignDoc.md` の「置く場所」の表。
- `apps/web/src/features/top-garden/DesignDoc.md` の、帯の絵のファイルの置き場と配置。乱数の順と SVG のサイズの上限の節を直すかも、あわせて決める。
- SVG の URL を接尾辞の付いた import で受けるときは、`context/conventions.md` の `import/default` の抑制の一覧と `oxlint.config.ts`。

## Considered Options

| 選択肢                                                 | 強み                                                                                                                                          | 弱み                                                                                                                           |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **採用:** 別の SVG を CSS の `mask-image` で帯に掛ける | JavaScript が無くても絵が出る。庭を出す訪問では取得しない。塗りをトークンの色にでき、SVG に色の値を書かない。LCP の候補にならない見込みである | 層ごとに 1 色になる。mask の中の filter の描かれ方を、ブラウザごとに確認する必要がある                                         |
| 別の SVG を `<img loading="lazy">` で置く              | JavaScript が無くても絵が出る。庭を出す訪問では取得しない                                                                                     | SVG の中に色の値か `prefers-color-scheme` を書く必要がある。`img` が LCP の候補になり、遅延の読み込みで LCP が遅れることがある |
| ADR-0080 のように、JavaScript で挿入する               | ADR-0080 と同じ仕組みで作れる                                                                                                                 | JavaScript が動かない環境で絵が出ない                                                                                          |
| SVG を HTML に入れる                                   | 読み込みが増えない                                                                                                                            | 庭を出す訪問にも配信する。ADR-0080 が避けた理由と同じ問題が出る                                                                |
| 版画風の `ArtBand`（`kasumi`、`moonPine`）を置く       | 既にあるコンポーネントで作れる。動きが 5 秒以内で、動きの規則の例外が要らない                                                                 | 墨の絵と画風が違う                                                                                                             |
| 帯に絵を置かない（ADR-0080 のまま）                    | 実装が要らない                                                                                                                                | 庭を出さない訪問者に、同じ画風の絵を出せない                                                                                   |

## Consequences

### Positive

- 庭を出さない訪問者にも、庭と同じ画風の絵を出せる。
- 庭を出す訪問では、SVG のファイルを取得しない。

### Negative

- 庭を出す訪問の HTML も、帯の要素と帯の CSS の分だけ増える。
- 帯の絵の SVG を、イントロの墨の絵と別に作って保つ必要がある。
- 庭を出さない訪問では、読み込みが 1 つ増える。
- 帯を動かす ADR では、mask の中の filter をフレームごとに描き直す負荷を確認する必要がある。
