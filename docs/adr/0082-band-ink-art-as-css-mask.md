# ADR-0082: 庭を出さないときのトップの帯に、墨の絵を CSS の mask で置き、止めるボタンのある動きを付ける

## Status

提案

## Context

庭を出さないときのトップ（ふつうのページ）の帯に、墨の絵を置くかと、置くならどう配信するかを決める必要がある。

- ADR-0026 は、庭を出さない訪問者にも同じ画風の絵を出すと決めていたが、ADR-0080 がその判断を置き換え、ふつうのページには墨の絵を置かないと決めた。
  - ADR-0026: [トップの最初の訪問で水墨の門を描き、門をくぐった立体の庭にプロフィールを置く](0026-sumi-gate-and-garden-on-top.md)
  - ADR-0080: [墨の絵と署名の SVG を、トップの HTML に入れず、最初の訪問のときだけ読み込む](0080-ink-gate-svg-loaded-on-first-visit.md)
- ADR-0080 が墨の絵を置かないとした理由は、使わない訪問に SVG（gzip で約 44 KB）を配信しないためである。HTML に入れると、庭を出す 2 回目以降の訪問にも配信される。
- 運営者は、2026-11-13 に、帯の絵を背景として動き続ける形にすると決めた。止めたことは `localStorage` に覚える。
- 庭を出さないのは、表示の設定で庭をオフにしたとき、表示の設定を保存せずに OS で動きを減らす設定にしているとき、JavaScript が動かない環境、WebGL が使えない環境である。JavaScript が動かない環境でも、止まった絵を出す必要がある。
- 庭を出すかは、`head` の inline script が本文を描く前に決め、庭を出すときは `html` に class `stage-on` を付ける。帯は、庭を出すときに `display: none` になる。
- 全体の Design Doc の動きの規則は、位置を動かさないこと、動きのために配る JavaScript を 0 バイトにすること、5 秒を超える動きを 5 秒以内に止めることを決めている。ADR-0026 は、前の 2 つの例外を庭にだけ認めている。
- 版画風の挿絵は、SVG に色の値を書かず、セマンティックトークンの文字と面の色で塗る。サイトのテーマは OS の設定に従う。
- 庭を出さないトップは、LCP が 2.5 秒以内で、Performance が 90 以上という要求の対象で、ADR-0078 の条件で測る。
  - ADR-0078: [トップの Lighthouse の合否を、Metal の GPU と simulate のスロットリングで 5 回測った中央値で判定する](0078-top-lighthouse-gpu-and-throttling.md)
- 帯の中が `display: none` のとき、別の SVG のファイルを取得するかを、出し方ごとに Chromium と WebKit で確認した。Firefox は確認していない。

  | 出し方                    | 帯が `display: none` | 帯を出す |
  | ------------------------- | -------------------- | -------- |
  | `<img>`                   | 取得する             | 取得する |
  | `<img loading="lazy">`    | 取得しない           | 取得する |
  | CSS の `background-image` | 取得しない           | 取得する |
  | CSS の `mask-image`       | 取得しない           | 取得する |

## Decision

庭を出さないときのトップの帯に、墨の絵を置く。
絵は、HTML に入れず、別の SVG のファイルを CSS の `mask-image` で帯の要素に掛け、塗りをトークンの色にする。

- ファイル
  - ビルドのときに `ink/` が、リポジトリの中の入力だけから、帯の高さに収まる配置の SVG を作る。`/_astro/` から、内容のハッシュを入れたファイル名で配信する。
  - SVG に色の値を書かない。墨の線の濃さは alpha で持ち、塗りは帯の要素の `background-color` に文字の色のトークンを当てる。
  - 動かす層（霞、近景の松）は、別の要素と別のファイルに分ける。
- 配信
  - HTML に入れるのは、帯の要素と止めるボタンだけにする。庭を出す訪問では帯が `display: none` なので、ファイルを取得しない。
  - 場面の読み込みに失敗してふつうのページに戻ったときは、帯を出した時点で取得する。
- 動き
  - 動きは、帯の CSS のアニメーションで付ける。JavaScript が `html` に class を付けたときだけ動かす。JavaScript が動かない環境では止まった絵になる。
  - 表示の設定のアニメーションがオフのとき（OS で動きを減らす設定で、表示の設定を保存していないときを含む）は、動かさない。
  - 何をどう動かすかは、運営者が案から選ぶ。
- 止めるボタン
  - 帯に「動きを止める」ボタンを置き、読み上げで名前が分かるようにする。止めたことを `localStorage` に覚え、次に開いたときも止まった絵を出す。
  - 帯の絵の要素は、`aria-hidden="true"` にして読み上げから外す。
- 動きの規則の例外
  - 帯の絵の動きは、5 秒を超える動きを 5 秒以内に止める規則の例外にする。止めるボタンが、WCAG 2.2.2 の止める手段にあたる。
    - 出典: [Understanding SC 2.2.2: Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)
  - 止めるボタンと、動かす class を付ける処理は、動きのために配る JavaScript を 0 バイトにする規則の例外にする。inline script に置き、別のファイルを読み込まない。
  - 選んだ案が位置を動かすとき（霞の流れ、松の揺れ）は、位置を動かさない規則の例外にする。帯は本文の上にあり、本文の罫の位置は動かないためである。

理由は、JavaScript が動かない環境でも止まった絵を出せ、庭を出す訪問の HTML を増やさず、ファイルも取得させないためである。
`mask-image` は、塗りをトークンの色にできるので、SVG に色の値を書かずにテーマに合わせられる。
`mask-image` の画像は LCP の候補にならないので、LCP は今と同じく本文の要素で決まる見込みである（未確認）。

## 承認の条件

- 運営者が、動きの案から 1 つを選ぶ。案は、霞が流れる、松が揺れる、霞の濃さが満ち引きする、の 3 つである。
- 実装の中で、次を確認する。
  - 庭を出す訪問で、帯の SVG のファイルの取得が 0 件である。
  - 庭を出さないトップを、ADR-0078 の条件（`--visit reduced-motion`）で、帯の有りと無しで測る。帯の有りが要求を満たさないときは、実装を止めて扱いを決め直す。
  - `feTurbulence` のかすれの filter が、`mask-image` の SVG の中でも、Chromium、WebKit、Firefox で同じに描かれる。描かれないときは、filter を外した見た目を運営者に見せる。
  - Firefox でも、帯が `display: none` のときにファイルを取得しない。

承認の後に直す文書は、次のとおり。

- ADR-0080 の、ふつうのページに墨の絵を置かない記述。
- ADR-0026 の、ふつうのページに墨の絵を置かない記述。
- `docs/adr/index.md` の「挿絵とトップの演出」の表と、移した判断の表。
- `packages/ui/src/art/DesignDoc.md` の「置く場所」の表。
- `docs/design/DesignDoc.md` の「動き」に、帯の絵の例外。
- `apps/web/src/features/top-garden/DesignDoc.md` の、帯の絵の配置と動き。

## Considered Options

| 選択肢                                                 | 強み                                                                                                                              | 弱み                                                                                                                             |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **採用:** 別の SVG を CSS の `mask-image` で帯に掛ける | JavaScript が無くても絵が出る。庭を出す訪問では取得しない。塗りをトークンの色にでき、SVG に色の値を書かない。LCP の候補にならない | 層ごとに 1 色になり、松の淡い緑のような色の差しは別の層が要る。mask の中の filter の描かれ方を、ブラウザごとに確認する必要がある |
| 別の SVG を `<img loading="lazy">` で置く              | JavaScript が無くても絵が出る。庭を出す訪問では取得しない                                                                         | SVG の中に色の値か `prefers-color-scheme` を書く必要がある。`img` が LCP の候補になり、遅延の読み込みで LCP が遅れることがある   |
| ADR-0080 のように、JavaScript で挿入する               | ADR-0080 と同じ仕組みで作れる                                                                                                     | JavaScript が動かない環境で絵が出ない                                                                                            |
| SVG を HTML に入れる                                   | 読み込みが増えない                                                                                                                | 庭を出す訪問にも配信する。ADR-0080 が避けた理由と同じ問題が出る                                                                  |
| 帯に絵を置かない（ADR-0080 のまま）                    | 実装も、動きの規則の例外も要らない                                                                                                | 庭を出さない訪問者に、同じ画風の絵を出せない                                                                                     |

## Consequences

### Positive

- 庭を出さない訪問者にも、庭と同じ画風の絵を出せる。
- 庭を出す訪問の HTML と通信は変わらない。

### Negative

- 動きの規則の例外が、庭のほかに 1 つ増える。
- 帯の絵の SVG を、イントロの墨の絵と別に作って保つ必要がある。
- 庭を出さない訪問では、読み込みが 1 つ以上増える。
