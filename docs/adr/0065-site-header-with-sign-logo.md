# ADR-0065: 全てのページに、イントロの署名をロゴにしたヘッダーを置き、ナビに記事とプレイグラウンドを並べる

## Status

提案

## Context

サイトのヘッダーに何を置くかと、イントロの署名をどこに出すかを決める必要がある。

- トップの最初の訪問で、左下に「Fukuemon」の署名を筆記体で書き、署名はイントロの間だけ出すと決めている。about は独立したページを作らず、ヘッダーの「筆者について」が `/` を指すと決めている。
  - ADR-0026: [トップの最初の訪問で水墨の門を描き、門をくぐった立体の庭にプロフィールを置く](0026-sumi-gate-and-garden-on-top.md)
- `fukuemon.dev` に置くページは、トップ、記事、シリーズ、プレイグラウンドの一覧である。プレイグラウンドのツールは `play.fukuemon.dev` に置く。
  - ADR-0031: [サブドメインに分ける規則を決め、1 つのアプリを 1 つの Worker とホスト名に割り当てる](0031-subdomains-and-workers.md)
- どのページからも、トップ、記事の一覧（`/articles`）、プレイグラウンドの一覧（`/playground`）へ移れる必要がある。プレイグラウンドの一覧へのリンクをどこに置くかは、どの文書にも書かれていない。
- 本文の検索は、記事が増えて一覧とシリーズから辿れなくなったときに作ると決めている。
- デザインシステムは、ヘッダーの外枠を 68rem にしてロゴの左端と本文の左端をそろえ、ヘッダーの下を 2px の墨の罫にし、ナビの今いるページの印を錆の筆の線にすると決めている。
  - ADR-0028: [操作できる要素と重なる面の角を 2px で丸め、重なる面にずらした影を付け、罫を引く動きを筆の線にする](0028-radius-shadow-and-brush-motion.md)
- 運営者は、ヘッダーを置く案、パンくずと末尾のリンクで移る案、フッターだけに置く案を比べ、ヘッダーを置く案を選んだ。
- 運営者は、ヘッダーのロゴを「fukuemon.dev」の文字ではなく、イントロの署名にすると決めた。署名の高さを 24px、32px、40px で比べ、40px を選んだ。
- 署名の SVG は、運営者の自筆に差し替えられる作りにしている。

## Decision

全てのページに、イントロと同じ署名をロゴにしたヘッダーを置く。
ナビには「記事」と「プレイグラウンド」の 2 つを並べる。

- ヘッダーの左に、イントロと同じ署名の SVG を、高さ 40px のロゴとして置く。ロゴは `/` へリンクし、読み上げの名前は「Fukuemon」にする。
  - 署名の SVG のファイルは、イントロとヘッダーで 1 つにする。自筆の署名に替えると、両方が替わる。
  - イントロの間だけ出すのは、最初の訪問の左下の署名である。ヘッダーのロゴは、全てのページで出す。
- ヘッダーの右のナビに、「記事」（`/articles`）と「プレイグラウンド」（`/playground`）を置く。
  - トップがプロフィールで、ロゴがトップを指すので、「筆者について」の項目は置かない。
  - 検索の欄は置かない。
- ナビの今いるページの印は、リンク先そのもののページと、その下のページ（記事の一覧の下の記事など）に付ける。
  - 読み上げには、リンク先そのものでは `aria-current="page"`、その下のページでは `aria-current="true"` を渡す。記事のページで、「記事」を今のページと伝えないためである。
  - トップでは、ロゴに `aria-current="page"` を付ける。

## Considered Options

| 選択肢                                                            | 強み                                                                                               | 弱み                                                         |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| **採用:** 全てのページに、署名のロゴと 2 つのナビのヘッダーを置く | どのページからも、トップ、記事の一覧、プレイグラウンドの一覧に 1 回で移れる。JavaScript なしで動く | トップの庭の絵の上にヘッダーが重なる                         |
| ヘッダーを置かず、パンくずと記事の末尾のリンクで移る              | 庭の絵に何も重ならない                                                                             | 記事からプレイグラウンドの一覧へ移るのに 2 回押す            |
| フッターだけにリンクを置く                                        | 上端に何も無く、版面が最も軽い                                                                     | 長い記事では、最後まで送らないと移れない                     |
| ロゴを「fukuemon.dev」の文字にする                                | 明朝の見出しと書体がそろう                                                                         | イントロの署名と別の印になり、運営者の自筆に替えても揃わない |

## Consequences

### Positive

- どのページからも、トップ、記事の一覧、プレイグラウンドの一覧に移れる。
- 自筆の署名に替えると、イントロとヘッダーのロゴが同時に替わる。

### Negative

- トップの庭の上にヘッダーが重なる。
- 欧文の筆記体のロゴは、明朝の見出しと墨の罫の版面の中で、ここだけ洋風に見える。
- 幅 360px 以下では、ナビがロゴの下の 2 段目に折り返す。
