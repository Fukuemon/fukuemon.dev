# ADR-0067: コードを動かす画面の詰めたペインの文字のトークンを 4 つにし、13px の等幅の行高に DADS に無い値を使う

## Status

提案

## Context

コードを動かす画面のペインを隙間なく並べ、行を 24px に詰めたときの、文字のトークンを決める必要がある。

- コードを動かす画面だけ、文字を 12px と 13px まで、押せる領域を 24×24 CSS px まで小さくすると決めている。テーマ変数には、`text-compact`（12px）と `text-label-compact`（太字の 13px）の 2 つを置くとしている。
  - ADR-0062: [コードを動かす画面だけ、文字を 12px と 13px まで、押せる領域を 24×24 CSS px まで小さくする](0062-dense-text-and-targets-in-playground.md)
- プリミティブトークンの書体の太さ、文字の大きさ、行高は、DADS の `@digital-go-jp/design-tokens` 2.1.0 の値を使うと決めている。
  - ADR-0024: [トークンを、fukuemon.dev の値のプリミティブトークン、セマンティックトークン、テーマ変数の 3 つの層にし、生成りの地と旧サイトの差し色で、角丸と影を使わない版面にする](0024-tokens-of-fukuemon-dev.md)
- コードを動かす画面は、ペインの間の隙間と外側の余白をなくし、木の行を 24px、HTTP の流れの行を約 44px に詰めた。
- 詰めたペインの文字には、ADR-0062 の 2 つのほかに、標準の太さの 13px と、13px の等幅（エディタ、端末、HTTP のメソッドと URL）が要る。標準の太さの 13px は、ファイルの木の行、入力欄の値、表のセル、メニューの項目、開閉の中身、空の状態の文に使う。
  - ADR-0062 は、13px にしてよい文字を「コードと操作のラベル」としている。木の行、入力欄の値、表のセル、メニューの項目、開閉の中身、空の状態の文は、この範囲に入らない。
  - 13px の等幅の文字を、VS Code と StackBlitz の行の間隔（12px の文字で 18px）に近い約 20px の行に置くには、DADS の行高（100%、130%、150%、160%、170%）に無い値が要る。

## Decision

- テーマ変数に、`text-compact`（12px）と `text-label-compact`（太字の 13px）に加えて、次の 2 つを置く。
  - `text-body-compact`: 標準の太さの 13px。行高は 130%。
  - `text-code-compact`: 13px の等幅。行高は 154%（約 20px）。
- 154% は DADS の行高に無いので、プリミティブトークンに足す。DADS の 150% では、行は 19.5px になる。
- 13px にしてよい文字を、コードと操作のラベルに加え、木の行、入力欄の値、表のセル、メニューの項目、開閉の中身、空の状態の文に広げる。
- 4 つのトークンは、コードを動かす画面のコンポーネントの外で使わない。使う場面は、デザインシステムの Design Doc の文字の表に書く。
- 理由は次のとおり。
  - ファイルの木の行と名前を、太字にせずに 13px で書ける。
  - エディタの行が、VS Code と StackBlitz の行の間隔に近くなる。

ADR-0062 の Decision のうち、テーマ変数に置く compact のトークンを 2 つとした決定と、13px にしてよい文字をコードと操作のラベルとした範囲を、この Decision が置き換える。  
ADR-0024 の Decision のうち、行高を DADS 2.1.0 の値に限った決定を、154% についてだけ、この Decision が置き換える。

## 承認の条件

- 承認のときに、ADR-0062 と ADR-0024 の Status に、置き換えた範囲を書く。

## Verification

カタログの「画面/コードを動かす画面」を、Chromium の 1600x900 で開いて確認した。

- 13px の等幅の行の高さは 20.02px だった。
- Safari と Firefox での確認はしていない。

## Considered Options

| 選択肢                                                                       | 強み                                                                                      | 弱み                                                               |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **採用:** 標準の太さの 13px と等幅のトークンを足し、等幅の行高に 154% を使う | ファイルの木の行と名前が太字にならない。エディタの行が VS Code と StackBlitz の間隔に近い | トークンが 4 つになる。DADS に無い行高が 1 つ増える                |
| `text-label-compact` に標準の太さの指定を重ねる                              | トークンが増えない                                                                        | 使う側ごとに太さを書き、トークンで文字のスタイルを決める形が崩れる |
| 等幅の行高を DADS の 150% にする                                             | DADS の値だけで済む                                                                       | 行が 19.5px になり、20px の行と合わない                            |

## Consequences

### Positive

- 詰めたペインの文字を、トークンだけで書ける。

### Negative

- DADS に無い行高が 1 つ増える。
