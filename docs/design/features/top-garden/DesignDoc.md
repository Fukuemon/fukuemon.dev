# トップの水墨の門と立体の庭

## Overview

トップ（`/`）の最初の訪問では、署名と水墨の門を筆の順に描き、色を差して立体の庭に移し、カメラが門をくぐる。  
2 回目以降の訪問は、門の内側の庭を、イントロなしで出す。  
プロフィールの 4 つのセクションは、庭の木の枝に掛けた和紙に置く。

この文書は、実装が試作のコードを読まずに同じ見た目を作れるよう、見た目の数値を持つ。  
数値は、`design/prototypes/top/` の試作の値である。  
サイトの全体像は [fukuemon.dev Design Doc](../../DesignDoc.md) にある。

- ADR-0026: [トップの最初の訪問で水墨の門を描き、門をくぐった立体の庭にプロフィールを置く](../../../adr/0026-sumi-gate-and-garden-on-top.md)
- ADR-0027: [トップの庭の絵を、訪問者の端末の日付と時刻で、季節と時間帯ごとに変える](../../../adr/0027-garden-by-season-and-time.md)

持たないもの。

## Design

### イントロの各段の時間

最初の訪問は、開いてから約 8.3 秒で終わる。  
署名を出さないときは、署名の段がなくなり、墨の絵から後ろの段が 0.6 秒早まる。

| 時刻        | 動き                                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------------------- |
| 0.2〜1.7 秒 | 左下に、筆記体の「Fukuemon」の署名を、左から書く                                                     |
| 0.6〜3.8 秒 | 紙の上に、山並み、塀、門、飛び石、石、松の順で、墨の線を筆の順に描く                                 |
| 3.8〜5.3 秒 | 墨の線の下に立体の庭の絵を出し、墨だけの絵から淡い色へ移す                                           |
| 5.1〜7.9 秒 | 墨の線と署名を消し、カメラが門をくぐる。近景の松の枝は、頭上へ抜ける                                 |
| 7.5〜8.2 秒 | 門の内側の、松の枝に掛けた和紙の前で止まり、プロフィールの文を出す。ヘッダーと、庭の中のボタンを出す |

- 色を差し始めるのは、墨の絵を描き終える時刻と、場面の準備が終わる時刻の、遅いほうである。
  - 墨の絵を描き終える時刻は、開いてからの時刻で決めず、墨の線と署名の CSS の遷移が終わった時刻にする。遷移は最初にスタイルが付いた時点から動くので、HTML が遅く届くと、その分だけ後ろにずれるためである。
  - 遷移を取れなかったときに早く色が差さないよう、開いてから 3.8 秒より前には色を差さない。
- 墨の門、塀、飛び石、石の線は、立体の配置を最初のカメラで投影した位置に描く。色が差すときに、線と立体がずれないためである。
- 墨の線は、SVG の `path` の `stroke-dashoffset` を CSS の遷移で動かして描く。
- 左下の署名は、イントロの間だけ出す。
- 文を出す時刻とカメラが止まる時刻は、色を差し始めた時刻からタイマーで決める。描くのが遅い端末でも、決めた長さで終わるためである。
- 「飛ばす」のボタン、Esc、Tab では、カメラを動かさずに、門の内側の最後の状態にする。
  - 「飛ばす」は、押したボタンが消えるので、プロフィールの見出しへフォーカスを移す。
  - Tab は、ブラウザのデフォルトの動作を止めず、最後の状態でそのまま次の要素へフォーカスを移す。Esc は、フォーカスを動かさない。
  - 場面の準備ができるまでは、最後の状態を描けないので、「飛ばす」のボタンを出さず、Esc と Tab を受けない。

### 墨の絵と署名の置き方

墨の絵は、設計の画面（1600 × 900）の座標で描いた SVG で、絵を置く枠の中央に置く。
絵の幅は、枠の縦横比で変える。
`cqw` と `cqh` は、枠の幅と高さの 1% である。

| 枠の縦横比                | 絵の幅                            |
| ------------------------- | --------------------------------- |
| 16:9 より横長             | 枠の幅（`100cqw`）                |
| 16:9 から正方形の手前まで | 枠の高さの 16/9 倍（`177.78cqh`） |
| 正方形か、正方形より縦長  | 枠の幅の 1.25 倍（`125cqw`）      |

- 墨の線: 色は `--fd-color-text` である。遠景の山並みはにじませ、中景と近景の線はかすれさせる。
- 松の円: 色は `--fd-color-primary` で、不透明度は 0.2 である。
- 署名: 色は `--fd-color-text` である。枠の左から `5cqw`、下から `4cqh` に置き、幅は `clamp(11rem, 24cqw, 24rem)` にし、反時計回りに 5 度回す。

墨の絵と署名の色と長さは、`InkGate.astro` の `<style>` に、セマンティックトークンと値を直に書く。
デザインシステムの規則（色はテーマ変数のユーティリティで書く）の例外である。
SVG を `set:html` で HTML に置くので、SVG の中の `path` にユーティリティを付けられないためである。

イントロの遷移とアニメーションの時間とイージングも、`InkGate.astro` と `GardenStage.astro` の `<style>` に値を直に書く。
デザインシステムの規則（動きはテーマ変数のユーティリティで書く）の例外である。
値はこの文書の「イントロの各段の時間」の時刻に合わせたイントロだけのもので、ほかの画面では使わないためである。

### 季節と時間帯の決め方

`head` のスクリプトが、ページを開いた時点の端末の日付と時刻で、季節と時間帯を決める。

| 季節           | 月       |
| -------------- | -------- |
| 春（`spring`） | 3〜5 月  |
| 夏（`summer`） | 6〜8 月  |
| 秋（`autumn`） | 9〜11 月 |
| 冬（`winter`） | 12〜2 月 |

| 時間帯          | 時刻      |
| --------------- | --------- |
| 朝（`morning`） | 5〜10 時  |
| 昼（`day`）     | 10〜16 時 |
| 夕（`evening`） | 16〜19 時 |
| 夜（`night`）   | 19〜5 時  |

- 境目の時刻は、後ろの時間帯に入る。10 時は昼、19 時は夜になる。
- 場面の色は、時間帯で決める。紙と墨の色（イントロの墨の絵、端の余白、色が差す前の「飛ばす」のボタン）は、テーマで決める。
- 開いたまま OS のテーマが変わったら、紙と墨の色をトークンから読み直し、庭を描き直す。場面の色は変えない。
- 夜の場面の端の余白だけは、テーマの紙の色を使わず、夜の `mist` の色にする。

### 和紙の文

文は DOM のまま、three の CSS3DRenderer で 3D に置く。  
3D の場面の 1 m は、文の 260px に当たる。

| 項目           | 画面の幅が 768px 以上のとき | 768px より狭いとき |
| -------------- | --------------------------- | ------------------ |
| 文の幅         | 25rem                       | 17.5rem            |
| 字の大きさ     | 1rem                        | 1rem               |
| 行間           | 1.9                         | 1.8                |
| 見出しの大きさ | 1.5rem                      | 1.5rem             |

- 見出しは、下に 0.625rem の余白をとって、字の色を 35% にした罫を引き、罫の下を 1rem あける。
- 段落の間は、1rem あける。
- 一覧の行は、上下に 0.625rem の余白をとり、字の色を 25% にした罫で区切る。
- 和紙は、文の左右に 0.18 m、上下に 0.2 m の余白を持つ。和紙の上下に軸木を付け、2 本の紐で木から伸びる枝に掛ける。
- 和紙を掛ける木は 4 本である。門の内側の松（プロフィール）、季節の木（経歴）、池のほとりの松（技術スタック）、灯籠のそばの季節の木（記事）の順に並ぶ。
- 見せる文は、今いる場所の 1 つだけにする。ほかの場所の和紙は、字の無い紙として見え、クリックを受けない。
- 文は、0.7 秒で不透明度を上げて出す。
- 庭を出したまま画面の幅が 768px をまたいだときは、和紙の大きさをセクションの大きさから測り直し、和紙と枝を掛け直す。
  文の幅は、768px をまたいだときだけ変わるためである。

### 庭の中のボタンの並び

庭の中のボタンは、画面の下に固定する。  
画面の端から、幅が 768px 以上のときは 1.25rem、768px より狭いときは 0.5rem 離す。

- 4 つの文へ移るボタンは、隣どうしの境の線を 1 本にしてつなぐ。
  - ボタンは、霞の色の面に、時間帯の枠の色（`garden-edge-day`、`garden-edge-night`）の枠を付ける。
  - 角は丸めない。4 つのボタンで 1 本の帯にするので、ボタンの間に角が出ないようにするためである。
  - 今いる場所のボタンは、背景と字の色を反転する。
- 「動きを止める」と「文だけで読む」は、下線を付けた字のボタンにして、1rem の間をあけて並べる。
  - 押した状態の「動きを止める」は、下線を 2px にする。
- 幅が 768px 以上のときは、4 つの文へ移るボタンと 2 つの操作を、1.5rem の間をあけて 1 段に並べ、下の中央に置く。
- 幅が 768px より狭いときは、2 段にする。上の段に 4 つの文へ移るボタン、下の段に 2 つの操作を、それぞれ中央に並べる。
- ボタンの字は、操作の字の `text-label`（16px）である。
- 4 つの文へ移るボタンの左右の余白は、幅が 768px 以上のときは 1rem、768px より狭いときは 0.25rem にし、幅と高さを 44px 以上にする。
  - 幅 320px でも、押せる大きさ（`TARGET-SIZE`）を保ったまま 4 つのボタンを 1 段に収めるためである。
- イントロの間は、場面の準備ができてから文を出すまで、「飛ばす」のボタンだけを右下に出す。
  - ボタンは、面に枠を付け、角を丸めない。
  - 面と枠と字は、色が差す前はテーマの紙と墨の色にし、色が差した後は、庭の中のボタンと同じく時間帯の色にする。
  - 画面の端からの距離は、庭の中のボタンと同じにする。

### ヘッダーと霞

庭を出している間、サイトのヘッダーは、背景を透明にし、下の罫を消して、画面の上端に重ねる。  
字が場面の色に重なって読みにくくならないよう、画面の上端と下端に霞を敷き、ヘッダーのロゴとリンク、庭の中の字のボタンを霞の上に置く。  
ヘッダーは、`stage-on` が付いた時点で文書の流れの外に置き、庭を描くまでは庭の面の下に隠す。  
庭を描いた時点で外すと、本文が上へずれ、CLS に数えられるためである。  
庭を描けずに `stage-on` を外したときは、ヘッダーが文書の流れに戻り、本文がヘッダーの高さだけ下がる。

霞の高さと、霞の色で塗りつぶす範囲は次のとおり。

| 霞   | 高さ                                                   | 霞の色で塗りつぶす範囲 |
| ---- | ------------------------------------------------------ | ---------------------- |
| 上端 | 6.5rem                                                 | 上から 65%             |
| 下端 | 768px 以上のときは 6.5rem、768px より狭いときは 8.5rem | 下から 65%             |

- 残りの範囲は、霞の色から透明へ、縦の線形のグラデーションで薄くする。
- 面を持たない字（ヘッダーのロゴとリンク、2 つの操作）は、霞の色で塗りつぶす範囲に収める。
  4 つの文へ移るボタンは、霞の色の面を持つので、範囲から出てもよい。
- 768px より狭いときは、ヘッダーのロゴの高さを 2rem、ロゴとリンクの間とリンクどうしの間を 0.5rem にする。
  幅 320px でも、ヘッダーを 1 段に収めるためである。
- 霞、字、ボタンの枠、フォーカスの輪の色は、和紙と同じく時間帯で決め、テーマに依らない。
  どれもセマンティックトークンで、組はコントラストのチェック（`pnpm run check:contrast`）が確認する。

| 時間帯     | 霞の色              | 字とフォーカスの輪の色 | ボタンの枠の色      |
| ---------- | ------------------- | ---------------------- | ------------------- |
| 朝、昼、夕 | `garden-mist-day`   | `garden-ink-day`       | `garden-edge-day`   |
| 夜         | `garden-mist-night` | `garden-ink-night`     | `garden-edge-night` |

- 庭を出している間は、ヘッダー、庭の中のボタン、霞の範囲で、`surface`、`text`、`border-field`、`focus` をこの表の色に差し替える。
  イントロで色が差した後は、「飛ばす」のボタンの範囲でも差し替える。
  ヘッダーとボタンのコードは、テーマの色の名前のまま書く。

## Interface

### ページが持つ状態

`head` のスクリプトは、次の値を書く。

| 置き場                          | 値                                     |
| ------------------------------- | -------------------------------------- |
| `html` の `data-season`         | `spring`、`summer`、`autumn`、`winter` |
| `html` の `data-time`           | `morning`、`day`、`evening`、`night`   |
| `html` の class `stage-on`      | 庭を出す                               |
| `html` の class `intro`         | 最初の訪問のイントロを出す             |
| `localStorage` の `fd-top-seen` | 端末でトップを開いたことがある         |

- 動きを減らす設定のときは、`stage-on` を付けず、場面のバンドルを読み込まない。
- `localStorage` を読めないか書けない端末では、最初の訪問かを判定できないので、`intro` を付けず、庭だけを出す。
- `fd-top-seen` は、庭を出すかにかかわらず、ページを開いた時点で書く。
- 場面のバンドルの読み込みに失敗したら、`stage-on` と `intro` を外し、ふつうのページにする。書いた `fd-top-seen` は消さない。
- WebGL を使えない端末でも、読み込みに失敗したときと同じく、`stage-on` と `intro` を外し、ふつうのページにする。
- ページを開いてから 6 秒たった時点で、場面のバンドルが `scene-ready` を書いていなければ、`stage-on` と `intro` を外し、ふつうのページにする。通信が応答を返さずに止まると、読み込みの失敗が届かないためである。この判定は、2 回目以降の訪問でも行う。
  - 6 秒の時点で場面を組み立てている途中なら、組み立て終えてから判定する。組み立ては同期の処理でメインスレッドを占め、その間はタイマーの関数が動かないためである。

場面のバンドルは、庭を描き始めた後に、次の値を書く。

| 書く先                                                             | 値                                                 |
| ------------------------------------------------------------------ | -------------------------------------------------- |
| `html` の class `scene-ready`                                      | 場面を組み立て、最初の 1 枚を描いた                |
| `html` の class `enter`                                            | 最初の訪問のイントロで、色を差して門をくぐる間     |
| `html` の class `garden-ready`                                     | 庭を描き、和紙と庭の中のボタンを出せる             |
| `html` の class `no-anim`                                          | イントロを飛ばした直後で、遷移を止める             |
| `html` の CSS 変数 `--scene-paper`、`--scene-text`、`--scene-link` | 和紙の背景、字、リンクの字の色（時間帯の場面の色） |
| `html` の CSS 変数 `--scene-pad-x`、`--scene-pad-y`                | 和紙の、文の外の左右と上下の余白                   |
| セクションの class `is-current`                                    | 今いる場所の文                                     |

- 最初の訪問では、`garden-ready` を、文を出す時刻（7.5 秒）に書き、カメラが止まる時刻（8.3 秒）に `intro` と `enter` を外す。
- 場面を組み立てた時刻、色を差し始めた時刻、イントロを終えた時刻を、`performance.mark` の `garden-scene-ready`、`garden-enter`、`garden-intro-done` で記録する。E2E が、イントロの段の時刻を確認するために読む。
- 「文だけで読む」を押したときと、描く途中の例外か WebGL のコンテキストの喪失で描けなくなったときは、この値をすべて外し、セクションを元の場所に戻し、`stage-on` と `intro` を外す。

### 場面のバンドル

場面のバンドルは、three と場面のモジュールを 1 つにまとめた JavaScript のファイルである。
トップの `head` の inline script が、庭を出すときだけ、module の script で読み込む。

- バンドルの大きさの上限は、gzip で 160 KB（160,000 バイト）である。
  - ビルドの後に `pnpm run check:garden-bundle` が確認する。
- バンドルは、ビルドのときに Vite が IIFE の 1 ファイルにまとめ、ファイル名にハッシュを付けて `/_astro/` に置く。
  - 開発サーバーはバンドルを ES モジュールのまま配るので、どちらでも動く module の script で読み込む。
- 場面の色は、デザインシステムのトークンの対象の外である（[デザインシステムの Design Doc の Scope](../../../../packages/ui/DesignDoc.md#scope)）。
