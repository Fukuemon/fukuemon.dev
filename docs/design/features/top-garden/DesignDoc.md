# トップの水墨の門と立体の庭

## Overview

トップ（`/`）の最初の訪問では、署名と水墨の門を筆の順に描き、色を差して立体の庭に移し、カメラが門をくぐる。  
2 回目以降の訪問は、門の内側の庭を、イントロなしで出す。  
プロフィールの 4 つのセクションは、庭の木の枝に掛けた和紙に置く。

この文書は、実装が試作のコードを読まずに同じ見た目を作れるよう、見た目の数値を持つ。  
数値は、`design/prototypes/top/` の試作の値である。  
サイトの全体像は [fukuemon.dev Design Doc](../../DesignDoc.md) にある。

- ADR-0026: [トップの最初の訪問で水墨の門を描き、門をくぐった立体の庭にプロフィールを置く](../../../adr/0026-sumi-gate-and-garden-on-top.md)
- ADR-0027: [トップの庭の絵を、訪問者の端末の日付と時刻で、季節と時間帯ごとに変える](../../../adr/0027-garden-by-season-and-time.md)

## Scope

持つもの。

- 季節と時間帯の決め方

- 和紙の文の幅、行間、見出しの大きさ、余白
- 庭の中のボタンの並び

持たないもの。

- 版画風の挿絵の版の仕様。[挿絵の Design Doc](../../../../packages/ui/src/art/DesignDoc.md) が持つ。

- 動きの規則と、トップの庭の例外。[全体の Design Doc の「動き」](../../DesignDoc.md#動き) が持つ。

## Design

### イントロの各段の時間

最初の訪問は、開いてから約 8.3 秒で終わる。  
署名を出さないときは、署名の段がなくなり、墨の絵から後ろの段が 0.6 秒早まる。

| 時刻        | 動き                                                                                           |
| ----------- | ---------------------------------------------------------------------------------------------- |
| 0.2〜1.7 秒 | 左下に、筆記体の「Fukuemon」の署名を、左から書く                                               |
| 0.6〜3.8 秒 | 紙の上に、山並み、塀、門、飛び石、石、松の順で、墨の線を筆の順に描く                           |
| 3.8〜5.3 秒 | 墨の線の下に立体の庭の絵を出し、墨だけの絵から淡い色へ移す                                     |
| 5.1〜7.9 秒 | 墨の線と署名を消し、カメラが門をくぐる。近景の松の枝は、頭上へ抜ける                           |
| 7.5〜8.2 秒 | 門の内側の、松の枝に掛けた和紙の前で止まり、名乗りの文を出す。ヘッダーと、庭の中のボタンを出す |

- 色を差し始めるのは、墨の絵を描き終える時刻と、場面の準備が終わる時刻の、遅いほうである。
- 墨の門、塀、飛び石、石の線は、立体の配置を最初のカメラで投影した位置に描く。色が差すときに、線と立体がずれないためである。
- 墨の線は、SVG の `path` の `stroke-dashoffset` を CSS の遷移で動かして描く。
- 署名は、イントロの間だけ出す。

### 墨の絵と署名の置き方

墨の絵は、設計の画面（1600 × 900）の座標の SVG を、画面の中央に置く。
絵の幅は、画面の縦横比で変える。`cqw` と `cqh` は、絵を置く枠の幅と高さの 1% である。

| 画面の縦横比        | 絵の幅                            |
| ------------------- | --------------------------------- |
| 16:9 より横長       | 枠の幅（`100cqw`）                |
| 16:9 から正方形まで | 枠の高さの 16/9 倍（`177.78cqh`） |
| 正方形より縦長      | 枠の幅の 1.25 倍（`125cqw`）      |

| もの   | 値                                                                                                                  |
| ------ | ------------------------------------------------------------------------------------------------------------------- |
| 墨の線 | 色は `--fd-color-text`。遠景の山並みはにじませ、中景と近景の線はかすれさせる                                        |
| 松の円 | 色は `--fd-color-primary` で、不透明度は 0.2                                                                        |
| 署名   | 色は `--fd-color-text`。枠の左から `5cqw`、下から `4cqh` に置き、幅は `clamp(11rem, 24cqw, 24rem)`、左に 5 度傾ける |

### 季節と時間帯の決め方

`head` のスクリプトが、ページを開いた時点の端末の日付と時刻で、季節と時間帯を決める。

| 季節           | 月       |
| -------------- | -------- |
| 春（`spring`） | 3〜5 月  |
| 夏（`summer`） | 6〜8 月  |
| 秋（`autumn`） | 9〜11 月 |
| 冬（`winter`） | 12〜2 月 |

| 時間帯          | 時刻      |
| --------------- | --------- |
| 朝（`morning`） | 5〜10 時  |
| 昼（`day`）     | 10〜16 時 |
| 夕（`evening`） | 16〜19 時 |
| 夜（`night`）   | 19〜5 時  |

- 境目の時刻は、後ろの時間帯に入る。10 時は昼、19 時は夜になる。
- 場面の色は、時間帯で決める。紙と墨の色（イントロの墨の絵、端の余白、ボタン）は、テーマで決める。
- 夜の場面の端の余白だけは、テーマの紙の色を使わず、夜の `mist` の色にする。

### 和紙の文

文は DOM のまま、three の CSS3DRenderer で 3D に置く。  
3D の場面の 1 m は、文の 260px に当たる。

| 項目           | 画面の幅が 640px を超えるとき | 640px 以下のとき |
| -------------- | ----------------------------- | ---------------- |
| 文の幅         | 25rem                         | 17.5rem          |
| 字の大きさ     | 1rem                          | 1rem             |
| 行間           | 1.9                           | 1.8              |
| 見出しの大きさ | 1.5rem                        | 1.5rem           |

- 見出しは、下に 0.625rem の余白をとって、字の色を 35% にした罫を引き、罫の下を 1rem あける。
- 段落の間は、1rem あける。
- 一覧の行は、上下に 0.625rem の余白をとり、字の色を 25% にした罫で区切る。
- 和紙は、文の左右に 0.18 m、上下に 0.2 m の余白を持つ。和紙の上下に軸木を付け、2 本の紐で木から伸びる枝に掛ける。
- 和紙を掛ける木は 4 本である。門の内側の松（名乗り）、季節の木（経歴）、池のほとりの松（技術スタック）、灯籠のそばの季節の木（読み物）の順に並ぶ。
- 見せる文は、今いる場所の 1 つだけにする。ほかの場所の和紙は、字の無い紙として見え、クリックを受けない。
- 文は、0.7 秒で濃度を上げて出す。

### 庭の中のボタンの並び

庭の中のボタンは、画面の下に固定し、画面の端から 1.25rem 離す。

- 4 つの文へ移るボタンは、境の線を重ねて 1 本につなぎ、下の中央に置く。
  - 今いる場所のボタンは、地と字の色を反転する。
- 「動きを止める」と「文だけで読む」は、下線を付けた字のボタンにして、右下に 1rem の間をあけて並べる。
  - 押した状態の「動きを止める」は、下線を 2px にし、字を太くする。
- 画面の幅が 900px 以下のときは、2 段にする。上の段に 4 つの文へ移るボタン、下の段に 2 つの操作を、それぞれ中央に並べる。
- ボタンの字は 0.875rem である。
- イントロの間は、「飛ばす」のボタンだけを右下に出す。

### ページが持つ状態

`head` のスクリプトは、次の値を書く。

| 置き場                          | 値                                     |
| ------------------------------- | -------------------------------------- |
| `html` の `data-season`         | `spring`、`summer`、`autumn`、`winter` |
| `html` の `data-time`           | `morning`、`day`、`evening`、`night`   |
| `html` の class `stage-on`      | 庭を出す                               |
| `html` の class `intro`         | 最初の訪問のイントロを出す             |
| `localStorage` の `fd-top-seen` | 端末でトップを開いたことがある         |

- 動きを減らす設定のときは、`stage-on` を付けず、場面の束を読み込まない。
- `localStorage` を読めないか書けない端末では、最初の訪問かを判定できないので、`intro` を付けず、庭だけを出す。

### 確認用のページ

`/ink` は、墨の絵と署名を、描き終えた後の止まった形で出す。
ライトとダークのテーマと画面の幅を変えて、絵と署名を確認するためのページで、検索エンジンに載せない。

- `/ink` は、墨の絵をトップに置くとき（#61 か #64）に消す。
- 本番の切り替え（#91）までに、必ず消す。
