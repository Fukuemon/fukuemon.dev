# fukuemon.dev のデザインシステムのコンポーネントとパターン

この文書は、[デザインシステムの文書](../DESIGN.md)の一部で、コンポーネントとパターンの使い方の規則を持つ。  
props と振る舞いは書かない。  
`src/base/`、`src/case/` のコードとカタログを参照先にする。  
DADS の指針から外れる規則は、その規則の隣に、DADS が求めることと外れる理由を書く。

## コンポーネント

コンポーネントは BCD Design で分類し、`packages/ui` には Base（`src/base/<名前>/`）と Case（`src/case/<名前>/`）だけを置く。  
ドメインを持つコンポーネント（サイトの帯、記事の一覧の行、プレイグラウンドの画面の配置）は、`apps/web` の `features/<機能>/components/` に置く。  
見た目は `variant` のような props で変え、呼び出す側から `className` で上書きしない。  
DADS にないコンポーネントは、WAI-ARIA Authoring Practices Guide（APG）のパターンのキーボードの操作に従う。

- 出典: [BCD Design によるコンポーネントの分類](https://qiita.com/misuken/items/19f9f603ab165e228fe1)
- 出典: [WAI-ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/patterns/)

### Button

- 使う場面: コードの写し、実行、ファイルの操作のように、画面の中で何かを起こす操作。
- 使わない場面と、代わりに使うもの: ほかのページへ移るときは `Link`。文字を持たない小さな操作は `IconButton`。
- 変種: `primary`、`secondary`、`danger` と、大きさの `M`、`S`。
  - DADS の文字だけのボタンは持たない。文字だけの操作は `Link` か `IconButton` で足りるためである。
  - `danger` は、ファイルの削除のように、データを失う操作を確定するボタンに使う。DADS のボタンには、この種類がない。
  - `primary` は、1 つの画面かダイアログに 1 つまでにする（`PRIMARY-ACTION-ONE`）。
- 状態: デフォルト、hover（`primary` と `danger`）、押している間、フォーカス、無効、読み込み中。読み込み中は、クリックを受け付けない。
  - 押している間は面を濃くし、離すと文字の色の墨がにじんで消える。無効と読み込み中のときは、どちらも出さない。
  - 読み込み中の `primary` と `danger` のボタンは、hover で色を変えない。押せない間に、押せるように見せないためである。
  - 無効のときに押せない理由の示し方: 無効は `aria-disabled` で表し、フォーカスを受けたまま押せなくする。押せるようにする条件の文をボタンの近くに出し、`aria-describedby` でボタンに結び付ける。送っている間と読み込みの間は、条件の文を出さず、待ちの印だけを出す。
  - 読み込み中の印は、ラベルを隠し、3 つの点が左から順に薄くなる形で示す。DADS のプログレスインジケーターは円を使うが、3 つの点は、動きを減らす設定で止まっても「…」と読めるためである。ボタンの幅は変わらない。
- 内容の制約: 子の文がボタンの名前になる。読み込み中も、文は隠すだけで名前に残る。
- キーボード: Enter と Space で押す。

### IconButton

- 使う場面: 題の右の操作、再読み込み、閉じるのように、印だけで意味が伝わる小さな操作。
- 使わない場面と、代わりに使うもの: 印だけで意味が伝わらない操作は、文を持つ `Button`。
- 変種: なし。
- 状態: デフォルト、hover、フォーカス、無効。
- 内容の制約: `label` を必ず渡す。`label` が読み上げの名前になる。
- キーボード: Enter と Space で押す。

### Link

- 使う場面: 本文の内部と外部のリンクと、記事の一覧の題のように文中に置かないリンク。
- 使わない場面と、代わりに使うもの: 画面の中で何かを起こす操作は `Button`。
- 変種: 内部と、`isExternal` の外部。外部のリンクは新しいタブで開き、読み上げに「（新しいタブで開く）」を足す。
  - 文中に置かないリンクには `isStandalone` を付け、左右を空けない。見出しや帯と左端をそろえるためである。
- 状態: デフォルト、hover、フォーカス、訪問済み。
  - hover で、下線の下に 2px の罫を左から 1 回引く。文中のリンクが折り返したときは、1 行目から順に全ての行に引く。
  - 文中に置かないリンクを flex の子にして折り返したときは、罫は最後の行の下にだけ、リンクの幅で出る。
  - フォーカスの表示は外へ 6px 広がるので、文中のリンクだけ左右を 6px 空け、前後の文字に重ねない。
  - 訪問済みのリンクは、色で分けない。DADS は訪問済みの色を分けるが、旧サイトと同じく内部のリンクの色を 1 つに保つためである。
- 内容の制約: `href` を必ず渡す。
- キーボード: Enter で移る。

### Tabs

- 使う場面: 記事の中の例の切り替えと、エディタのファイルのタブ。
- 使わない場面と、代わりに使うもの: 内容を開いて閉じるだけなら `Disclosure`。ページを移るなら `Link`。
- 変種: パネルの余白の `padded` と `flush`。タブごとの `closable`。
- 状態: デフォルト、hover、フォーカス、選択。選んだタブの下には、緑の筆の線を左から 1 回引く。
- 内容の制約: `label` をタブの並びの名前に渡す。
- キーボード: 左右の矢印のキーで隣のタブへ移り、端から反対の端へ回る。Home と End で端のタブへ移る。
  - DADS のタブには閉じるボタンがない。エディタのファイルのタブは、開いたファイルを閉じる操作が要るため、閉じるボタンを足す。
  - 閉じるボタンはマウスで押すためのもので、読み上げと Tab のキーの順から外す。タブの並び（`role="tablist"`）の中に、タブ以外の操作を置けないためである。
  - キーボードと読み上げでは、選んだタブで Delete のキーを押して閉じる。閉じられるタブは `aria-keyshortcuts="Delete"` を持つ。
  - マウスの中ボタンのクリックでも閉じる。Ctrl+W は、ブラウザのタブを閉じるキーと衝突するので割り当てない。

### Dialog

- 使う場面: 検索と、`ConfirmDialog` が組む確認。
- 使わない場面と、代わりに使うもの: 画面を止めずに知らせるだけなら `Notice`。操作の一覧は `ActionMenu`。
- 変種: なし。
- 状態: 開いている、閉じている。閉じると、開く前にフォーカスがあった要素へフォーカスを戻す。
  - `surface-raised` の面、1px の枠、2px の角、ずらした影で示す。DADS のモーダルダイアログはより大きい角丸とぼかした影を使うが、罫線の版面と合わないためである。
  - 開くと、濃度を上げて出て、上端に墨の筆の線を 1 回引く。
- 内容の制約: `title` を必ず渡す。主のボタンは 1 つまでにする（`PRIMARY-ACTION-ONE`）。
- キーボード: Esc で閉じる。開いている間、Tab のキーのフォーカスはダイアログの中に留まる。

### ActionMenu

- 使う場面: ファイルとディレクトリの操作のメニュー。
- 使わない場面と、代わりに使うもの: 操作が 1 つか 2 つなら、`Button` か `IconButton` を並べる。
- 変種: 項目ごとの `isDanger`。データを失う操作の項目を赤くし、最後に並べる。
- 状態: 閉じている、開いている、項目の hover とフォーカス。
- 内容の制約: `label` を開くボタンの名前に渡す。
- キーボード: 開くと最初の項目へフォーカスが移る。上下の矢印のキーで項目を移り、端から反対の端へ回る。Home と End で端の項目へ移る。Esc で閉じて開くボタンへフォーカスを戻し、Tab で閉じる。

### TextField

- 使う場面: 検索の語と、ファイルの名前の入力。
- 使わない場面と、代わりに使うもの: 検索の語と候補を一緒に扱うなら `SearchBox`。
- 変種: 枠の `boxed` と、下罫だけの `underline`。補足（`description`）、見出しを画面に出さない `isLabelHidden`、必須の表示。
  - `underline` は、検索の欄だけに使う。墨の下罫だけを引き、フォーカスすると緑の筆の線を左から 1 回引く。DADS のインプットテキストは枠と標準のフォーカスの表示を使うが、運営者が検索の欄の和の感じを罫で出すと決めたためである。例外の理由は [Design Doc の「フォーカスの表示」](../DesignDoc.md#フォーカスの表示)にある（`FOCUS-ONE`）。
- 状態: デフォルト、hover（`underline`）、フォーカス、エラー、無効。
  - エラーのときに色のほかに示すもの: `boxed` はデフォルトより太い赤の枠、`underline` は赤の罫にし、どちらも誤りの文を出す。誤りの文は `aria-describedby` で欄に結び付け、`role="alert"` を付けない。
- 内容の制約: `label` を必ず渡す。見出しを画面に出さないときも、`isLabelHidden` で読み上げに残す。案内の文（placeholder）を見出しの代わりにしない。
- キーボード: 入力欄の標準の操作だけを持つ。

### Table

- 使う場面: 記事の表、SQL の結果、HTTP のヘッダ。
- 使わない場面と、代わりに使うもの: 並びの見た目を揃えるだけで、行と列の意味を持たない内容には使わない。
- 変種: 見出しのセルの `scope`（`col`、`row`）。
- 状態: デフォルトと、幅に収まらない表の枠のフォーカス。
- 内容の制約: `caption` を必ず渡す。表の題になり、横に送る枠の名前にもなる。
- キーボード: 幅に収まらない表は、Tab のキーで枠にフォーカスし、左右の矢印のキーで横に送る。

### StatusBadge

- 使う場面: HTTP の状態コードと、記事の種別。
- 使わない場面と、代わりに使うもの: 押せる操作には使わない。文で知らせるなら `Notice`。
- 変種: `neutral`、`info`、`success`、`warning`、`danger`。HTTP の状態コードへの当て方は [Design Doc の「HTTP の流れの色」](../DesignDoc.md#http-の流れの色)にある。
- 状態: なし（押せない表示）。
- 内容の制約: `label` を必ず渡す。色だけで意味を伝えない（`STATE-NOT-COLOR-ONLY`）。
- キーボード: なし。

### Notice

- 使う場面: 記事の注意書きと、実行のエラー。
- 使わない場面と、代わりに使うもの: 入力欄ごとの誤りは、`TextField` の誤りの文。
- 変種: `info`、`success`、`warning`、`danger`。`isAlert` で、出たときに読み上げる。
  - 注意（`warning`）は錆の色にする。DADS は注意を黄か橙にするが、錆は橙に近い色相で、旧サイトの差し色であるためである。
- 状態: なし。
- 内容の制約: `title` を必ず渡す。`isAlert` は、送れなかったときと実行が失敗したときだけに使う。
- キーボード: なし。

### Disclosure

- 使う場面: 記事の補足と、リクエストとレスポンスの詳細。
- 使わない場面と、代わりに使うもの: 並んだ内容から 1 つを選んで見せるなら `Tabs`。
- 変種: 最初から開いた `defaultOpen`。
- 状態: 閉じている、開いている、hover、フォーカス。JavaScript が無くても開閉できる（`<details>`）。
- 内容の制約: `summary` に、開いて読める内容が分かる文を渡す。
- キーボード: Enter と Space で開閉する。

### Loading

- 使う場面: 実行環境の起動と、パッケージのインストールの待ち。
- 使わない場面と、代わりに使うもの: ボタンを押した後の待ちは、`Button` の読み込み中の状態。
- 変種: なし。
- 状態: 読み込み中だけ。薄い罫の上を主の色の罫が左から伸びて右へ抜ける。DADS のプログレスインジケーターは円を使うが、版面と同じ罫で組めるためである。
- 内容の制約: `label` を必ず渡し、何を待っているかを画面に出す。
- キーボード: なし。

### Breadcrumb

- 使う場面: 記事とシリーズの位置。
- 使わない場面と、代わりに使うもの: シリーズの前と次の記事へ移るなら `SeriesPager`。
- 変種: なし。
- 状態: リンクの hover とフォーカス。最後の項目は今のページで、リンクにしない。
  - hover で、リンクの箱の下に筆の線を左から 1 回引く（`brush-hover`）。線は箱に付けるので、ラベルが折り返しても 1 本で崩れない。
- 内容の制約: 最後の項目に、今のページの題を渡す。
- キーボード: リンクの標準の操作だけを持つ。

### TreeView

- 使う場面: `FileTree` と `ConsoleEntryList` が組む木の表示。
- 使わない場面と、代わりに使うもの: ファイルの作成、名前の変更、削除まで扱うなら `FileTree`。入れ子の無い一覧には使わない。
- 変種: 項目の高さの `default`（44px）と `compact`（24px）。`compact` は、コードを動かす画面のコンポーネントだけに使う。押せる領域を 44×44 CSS px 以上にする原則（`TARGET-SIZE`）の例外で、WCAG 2.2 の AA（2.5.8）の 24×24 CSS px 以上にする（ADR-0062）。
  - ADR-0062: [コードを動かす画面だけ、文字を 12px と 13px まで、押せる領域を 24×24 CSS px まで小さくする](../../../docs/adr/0062-dense-text-and-targets-in-playground.md)
- 状態: 枝の開閉、選択、hover、フォーカス。
- 内容の制約: `label` を木の名前に渡す。
  - 項目の `label` は、タイプアヘッドが探す文字列である。文字列の一部を太字にするために `content` を渡すときも、`label` と同じ文字列を描き、押せる要素を入れない。
- キーボード: APG の Tree View に従う。上下の矢印のキーで項目を移り、右の矢印のキーで枝を開いて子へ、左の矢印のキーで枝を閉じて親へ移る。Home と End で端の項目へ移り、Enter で選ぶ。
  - APG が必須にしない操作を 3 つ足す。
  - 文字を打つと、その文字で始まる項目へ移る（タイプアヘッド）。長い木で目的の項目へ早く移るためである。
  - `onRequestRename` を渡すと、項目で F2 のキーを押して名前の変更を呼べる。項目は `aria-keyshortcuts="F2"` を持つ。
  - `onRequestDelete` を渡すと、項目で Delete のキーを押して削除の確認を呼べる。項目は `aria-keyshortcuts="Delete"` を持つ。両方を渡すと、`aria-keyshortcuts` は `"F2 Delete"` になる。

### SplitPane

- 使う場面: エディタ、端末、プレビューの間の境界。
- 使わない場面と、代わりに使うもの: 大きさを利用者が変えない並びには使わない。
- 変種: 左右に分ける `horizontal` と、上下に分ける `vertical`。
- 状態: デフォルト、フォーカス、引いている間。
- 内容の制約: `label` を仕切りの名前に渡す。
- キーボード: APG の Window Splitter に従う。左右（`vertical` では上下）の矢印のキーで仕切りを動かし、Home と End で端まで動かす。

### FileIcon

- 使う場面: ファイルの木とエディタのタブの印。
- 使わない場面と、代わりに使うもの: 意味を伝える印には使わない。印は読み上げから外すので、意味は文で伝える。
- 変種: ファイルとディレクトリ。ファイルは、名前の拡張子からコード、文書、データ、そのほかの 4 つの系統を決め、線の形で見分ける。ディレクトリは開閉で形が変わる。
  - 色は、コードを藍（`info`）、文書を緑（`primary`）、データを墨、そのほかを薄い墨にする。錆は目次の現在地と注意の役割なので使わない。
- 状態: なし。
- 内容の制約: ファイルの名前を `name` に渡す。
- キーボード: なし。

### ArtBand

- 使う場面: 記事の一覧の冒頭の挿絵。トップの挿絵は水墨の門の絵と立体の庭で、`ArtBand` を使わない（ADR-0026）。
- 使わない場面と、代わりに使うもの: 記事の本文、コードを動かす画面、フッターには置かない（ADR-0026）。
- 変種: 図柄の `kasumi`、`seigaiha`、`moonPine` と、置き方の `band`、`fill`。図柄ごとの向く場所は [挿絵の Design Doc](../src/art/DesignDoc.md) にある。
- 状態: なし。読み込んだ直後に 1 回だけ動く。
- 内容の制約: 挿絵は読み上げから外す。挿絵に意味を持たせない。
- キーボード: なし。

### SearchBox

- 使う場面: 記事の検索の語の入力と候補。
- 使わない場面と、代わりに使うもの: 検索でない入力は `TextField`。
- 変種: なし。欄は `TextField` の `underline` で、送るボタンを置かず、Enter のキーで送る。欄が 1 つの form なので、JavaScript が無くても送れる。
  - 見出しは読み上げにだけ渡し、画面には虫眼鏡の印と、明朝の案内の文を出して欄の役割を示す。和の感じは、ボタンではなく欄の罫と書体で出す。
- 状態: 空、候補あり、候補を選んでいる、候補なし。候補が無いときは、その文を読み上げる。
- 内容の制約: `label` を必ず渡す。候補が無いときの文は `emptyMessage` で渡す。
- キーボード: APG の Combobox に従う。上下の矢印のキーで候補を移り、端から反対の端へ回る。候補を選んでいるときの Enter はその候補へ移り、それ以外の Enter は検索を送る。Esc で候補を閉じる。変換中の入力のキーは扱わない。

### TableOfContents

- 使う場面: 記事の見出しの一覧と、読んでいる見出しの表示。
- 使わない場面と、代わりに使うもの: 記事をまたぐ位置は `Breadcrumb`。
- 変種: 見出しの段の `2` と `3`。`3` の見出しは、直前の `2` の見出しの下に入る。
- 状態: リンクの hover とフォーカス、読んでいる見出し。読んでいる見出しは錆（`current-page`）の色と太字と左の罫で示し、JavaScript が動くときだけ出す。
  - hover で、見出しの文字のすぐ下に 2px の罫を左から 1 回引く（`link-rule`）。長い見出しは折り返すので、筆の線ではなく罫にする。
  - 罫は、行高 130% で折り返しても、次の行の文字に接しない。
- 内容の制約: 見出しを記事の順に渡す。
- キーボード: リンクの標準の操作だけを持つ。

### SeriesPager

- 使う場面: シリーズの中の前と次の記事へのリンク。
- 使わない場面と、代わりに使うもの: シリーズでない記事どうしのリンクは、本文の `Link`。
- 変種: なし。前か次の記事が無い側は描かない。
- 状態: リンクの hover とフォーカス。
  - hover で、面の色を替え、記事の題のすぐ下に 2px の罫を左から 1 回引く（`link-rule`）。題は折り返すので、筆の線ではなく罫にする。
  - 罫は、行高 130% で折り返しても、次の行の文字に接しない。
  - 題には下線を引くので、罫は下線に重なり、hover で下線が太くなる形に見える。
- 内容の制約: シリーズの名前、何本目か、全体の本数を渡す。
- キーボード: リンクの標準の操作だけを持つ。

### FileTree

- 使う場面: コードを動かす画面のファイルとディレクトリの一覧、作成、名前の変更、削除。`TreeView`、`ActionMenu`、`TextField` を組む。
- 使わない場面と、代わりに使うもの: 一覧を見せるだけなら、操作の props を渡さずに読むだけの木にする。
- 変種: 渡す操作（作成、ディレクトリの作成、名前の変更、削除）ごとに、題の右の操作とメニューの項目が出る。
- 状態: 選んだ項目あり、選んだ項目なし、作成中と名前の変更中の欄、メニューを開いている、空、読み込み中、エラー。削除は `ActionMenu` の `isDanger` の項目にする。
- 内容の制約: 空や空白だけの名前は確定しない。
- キーボード: `TreeView` の操作を継ぐ。F2 で名前の欄を開き、Enter で確定し、Esc で取り消す。Delete で、選んだ項目の削除（`onDelete`）を呼ぶ。確認のダイアログは呼ぶ側が `ConfirmDialog` で開く。

### ConfirmDialog

- 使う場面: ファイルの削除のような、データを失う操作を確定する前の確認。`Dialog` と `Button` を組む。
- 使わない場面と、代わりに使うもの: 戻せる操作には使わず、すぐに実行する。確認のほかに入力を求めるなら、`Dialog` で組む。
- 変種: なし。確定のボタンは `Button` の `danger` にする。
- 状態: 閉じている、開いている、確定の処理中。確定の処理中は、確定のボタンを読み込み中にし、やめるのボタン、Esc のキー、閉じるボタン、背景のクリックで閉じない。
- 内容の制約: 題と本文に、失うものの名前を入れる。本文には、戻せないことを書く。確定のボタンの文は、「削除する」のように操作の動詞にする。
- キーボード: 開くと、やめるのボタンにフォーカスを当てる。Enter のキーを続けて押しても、誤って確定しないためである。ほかは `Dialog` の操作を継ぐ。

### EditorFrame

- 使う場面: コードを動かす画面で、ファイルのタブと、エディタのエンジンと、下の状態の帯を置く。
- 使わない場面と、代わりに使うもの: 記事の中の書き換えないコードは、コードブロックで出す。
- 変種: コードの色のテーマ（`light`、`dark`）。`onClose` を渡すと、タブを閉じられる。
- 状態: 中身あり、ファイルを選んでいない空、読み込み中、エラー。タブの選択、hover、フォーカスは `Tabs` のとおり。
- 内容の制約: エンジンは、関数の子として渡す。枠はエンジンを選ばない。
- キーボード: `Tabs` の操作を継ぐ。閉じられるタブは、Delete のキーで閉じる。

### TerminalFrame

- 使う場面: コードを動かす画面で、端末の題と、端末のエンジンを置く。
- 使わない場面と、代わりに使うもの: 実行の結果を文で知らせるだけなら `Notice`。
- 変種: コードの色のテーマ（`light`、`dark`）。題の右の操作（`actions`）。
- 状態: 中身あり、空、読み込み中、エラー。
- 内容の制約: エンジンは、関数の子として渡す。枠はエンジンを選ばない。
- キーボード: 枠は操作を持たない。

### PreviewFrame

- 使う場面: コードを動かす画面で、プレビューの URL の欄と、iframe を置く。
- 使わない場面と、代わりに使うもの: 記事の中の図と画像は、本文に置く。
- 変種: `onReload` を渡すと、再読み込みのボタンが出る。
- 状態: 中身あり、空、読み込み中、エラー。URL の欄は書き換えられない。
- 内容の制約: iframe には `title` を付けて渡す。
- キーボード: 再読み込みのボタンは、Enter と Space で押す。

### HttpExchangeList

- 使う場面: 行き来したリクエストとレスポンスを順に並べる。者、メソッド、URL、状態コードを出す。
- 使わない場面と、代わりに使うもの: 1 つの行き来のヘッダと本文は `HttpExchangeDetail`。
- 変種: なし。
- 状態: 行の選択、hover、フォーカス、空、読み込み中、エラー。選んだ行は、主の色の左の罫で示す。
- 内容の制約: 者の色は、区別の色を流れの中で 1 色ずつ固定して当てる。1 つの流れの者は 6 つまでにする。状態コードと者の名前は、色と一緒に文字で出す（`STATE-NOT-COLOR-ONLY`）。
- キーボード: 行は Enter と Space で選ぶ。

### HttpExchangeDetail

- 使う場面: 1 つの行き来のヘッダ、Cookie、本文を出す。
- 使わない場面と、代わりに使うもの: 行き来の一覧は `HttpExchangeList`。
- 変種: なし。
- 状態: 中身あり、行き来を選んでいない空、読み込み中、エラー。届かなかったリクエストは、レスポンスの節を出さない。Cookie の節は、Cookie があるときだけ出す。
- 内容の制約: 長い URL とヘッダの値は折り返し、本文はその枠の中だけで横に送る。
- キーボード: 開閉の要約は `Disclosure` のとおり。本文の枠は Tab のキーでフォーカスし、矢印のキーで送る。

### ConsoleEntryList

- 使う場面: コードを動かす画面で、Node のプロセスとプレビューの `console.*` の出力を、起きた順に並べる。行ごとに、ログレベルの印、値、時刻、出力元を出す。
- 使わない場面と、代わりに使うもの: プロセスの出力のテキストをそのまま出すなら `TerminalFrame`。HTTP の行き来は `HttpExchangeList`。
- 変種: 最初に表示するログレベル（`defaultLevels`）。渡さないと、全てのログレベルを表示する。
- 状態: 行あり、空、選んだログレベルの行が無い、読み込み中、エラー。ログレベルのボタンが押されている状態と、値の木の開閉、hover、フォーカス。
  - ログレベルの色は [Design Doc の「コンソールのログレベルの色」](../DesignDoc.md#コンソールのログレベルの色)にある。印の形と、読み上げる名前（`console.*` の名前の `error` など）を色に重ねる（`STATE-NOT-COLOR-ONLY`）。
  - ログレベルのボタンは、押されている状態を色のほかに枠の中の印で示し、ボタンにそのログレベルの行の数を出す。
  - 高さは呼ぶ側が決める。高さを決めたときは、題とログレベルのボタンを残して、行の領域だけをスクロールさせる。
  - 行の領域は、キーボードでフォーカスして送れる。
  - 行の領域だけをスクロールさせるときは、親を高さの決まった縦方向の flex か grid にする。`SplitPane` の領域に置くときは、`flex h-full flex-col` の要素で包む。
  - 高さを決めない親では、コンソールは行の数だけ伸び、行が増えてもページをスクロールしない。
  - 一番下を見ている間に行が増えると、DevTools のコンソールと同じく、行の領域を一番下まで送る。上へ戻して読んでいる間は送らない。
  - 読み込み中、エラー、空（行が全て消えたとき）を挟むと、一番下を見ている扱いに戻し、行の領域を一番下まで送る。上へ戻して読んでいた位置は残さない。
  - ログレベルを外して戻すと、その行の値の木は閉じた状態で出る。読み込み中とエラーを挟んだときも同じである。
- 密度: `TEXT-MIN-SIZE` と `TARGET-SIZE` の例外である（ADR-0062）。
  - ADR-0062: [コードを動かす画面だけ、文字を 12px と 13px まで、押せる領域を 24×24 CSS px まで小さくする](../../../docs/adr/0062-dense-text-and-targets-in-playground.md)
  - 値の行は高さ 21px 以上で文字 12px（`text-compact`）、ログレベルのボタンは高さ 28px 以上で文字 13px（`text-label-compact`）にする。
  - 値の木は `TreeView` の `compact`（24px）にする。
- 内容の制約: 値は、記録の形から `ConsoleValue` に変換して渡す。行の数の上限と、上限を超えたときの古い行の扱いは、呼ぶ側が決める。
  - 値の深さ、要素の数、文字列の長さの上限も、呼ぶ側が決める。コンポーネントは、渡された値の全てを木にするためである。
- キーボード: ログレベルのボタンは、Tab のキーで移り、Enter と Space で押す。行の領域は、Tab のキーでフォーカスし、上下の矢印のキーで送る。配列、オブジェクト、`Error`、`Map`、`Set` の値は `TreeView` で表示し、操作は `TreeView` のとおり。

## パターン

`src/patterns/` に置くパターンは、まだ無い。  
コンポーネントの組み合わせが 2 つ以上の画面に出たら、目的、並べる領域と使うコンポーネント、狭い画面と広い画面での並び方を、ここに足す。
