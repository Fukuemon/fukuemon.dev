## カタログに載せてよいもの

<!-- カタログを開ける人の範囲を書く。載せてよいのは、コンポーネントとダミーのデータだけ -->

- 人の名前と組織の名前は、ダミーの値にする。実際の画面やデータベースからコピーしない。
- API を呼ぶ例を作らない。データは例の中か、ダミーのデータのファイルから渡す。
- カタログの原稿に、URL、ホスト名、シークレットを書かない。
