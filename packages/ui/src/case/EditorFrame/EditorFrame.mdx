# EditorFrame

ファイルのタブと、エディタのエンジンと、下の状態の帯を置く枠。

## 規則

規則の本文は、次の文書のセクションにある。

- 使う場面、使わない場面、変種、状態、内容の制約、キーボードの操作: `packages/ui/design/components.md` の「コンポーネント」の「EditorFrame」

### 低い枠

`minBodyHeight` に `none` を渡すと、エンジンを置く領域に最小の高さ（192px）を付けず、枠を置く側が決めた高さに合わせる。  
入力欄を低くして、結果の欄と縦に並べるときに使う。  
例は、高さ 160px の枠である。

<Canvas of={Stories.Short} />

### 起動を待つ空

`state` に `pending` を渡すと、題だけを出し、ファイルのタブ、コード、下の状態の帯を出さない。  
画面の全ての領域が同じ処理を待つ間に使う。  
待ちの印は `PageLoading` が画面の右下に出す。
