# ConsoleEntryList

`console.*` の出力を起きた順に並べ、ログレベルで絞って、値を開いて見るコンソール。

## 規則

規則の本文は、次の文書のセクションにある。

- 使う場面、使わない場面、変種、状態、内容の制約、キーボードの操作: `packages/ui/design/components.md` の「コンポーネント」の「ConsoleEntryList」
- 当たる原則: `packages/ui/DESIGN.md` の「画面を作るときの原則」の次の ID
  - `STATE-NOT-COLOR-ONLY`
  - `TARGET-SIZE`
  - `TEXT-MIN-SIZE`
