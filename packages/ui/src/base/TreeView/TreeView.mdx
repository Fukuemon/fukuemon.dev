# TreeView

階層を開いて閉じる木の表示。

## 規則

規則の本文は、次の文書のセクションにある。

- 使う場面、使わない場面、変種、状態、内容の制約、キーボードの操作: `packages/ui/design/components.md` の「コンポーネント」の「TreeView」
- 当たる原則: `packages/ui/DESIGN.md` の「画面を作るときの原則」の次の ID
  - `TARGET-SIZE`
  - `TEXT-MIN-SIZE`

### 詰めた項目（compact）

コードを動かす画面のコンソールの値の木に使う。  
項目の高さは 24px、文字は 12px である（ADR-0062）。

<Canvas of={Stories.Compact} />

### 選ぶ操作の無い木

`onSelect` を渡さない木は、項目を選ばない。  
Enter と Space のキーで、枝を開閉する。  
コンソールの値の木に使う。

<Canvas of={Stories.WithoutSelect} />

<Canvas of={Stories.Focus} />

### 13px の詰めた項目（compact、body-compact）

ファイルの木に使う。  
項目の高さは 24px、文字は 13px である（ADR-0062、ADR-0067）。  
選んだ項目は太字にせず、面の色と左の 2px の主の色の罫で示す。

<Canvas of={Stories.CompactBody} />

### 名前の欄を開いている

`TreeView` は、`editor` に渡した欄を、項目の名前の代わり（`rename`）か、枝の子の先頭に足した行（`insert`）に描く。  
この story では、閉じた `routes` の子の先頭に `insert` の行を足す。  
`TreeView` は、欄を描く間、欄のある行までの閉じた枝を開く。
