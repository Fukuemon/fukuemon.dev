# 動き

画面のコードが動きを付けるときのユーティリティを、見本と使う場面で並べる。
見本の動きは、hover、押す操作、横に送る操作をするか、ページを開くと見える。
処理中の印だけは繰り返す。
ページを開いたときに 1 回だけ動く見本は、ページを読み込み直すと、もう一度動く。

- 使う場面と規則: `packages/ui/design/tokens.md` の「レイアウト、区切り、重なり、動き」
- 動きを付ける操作、長さ、付けない所: `packages/ui/DesignDoc.md` の「動き」
- 当たる原則: `packages/ui/DESIGN.md` の「画面を作るときの原則」の `MOTION-TOKEN`、`MOTION-REDUCE`
- 値: `src/tokens/theme.css`
