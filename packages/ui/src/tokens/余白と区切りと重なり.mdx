# 余白と区切りと重なり

画面のコードが余白、区切りの罫、重なる面、フォーカスの表示を書くときのユーティリティを、見本と使う場面で並べる。

- 使う場面と規則: `packages/ui/design/tokens.md` の「レイアウト、区切り、重なり、動き」
- 当たる原則: `packages/ui/DESIGN.md` の「画面を作るときの原則」の `SPACING-SCALE`、`FOCUS-ONE`
- 値: `src/tokens/theme.css`

## 余白

Tailwind のデフォルトの段（`p-2`、`gap-4` など。1 段 4px）: 全ての余白。ブロックの間は 8px の倍数（偶数の段）にする

      </div>

  </div>
</Unstyled>
