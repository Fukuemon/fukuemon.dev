# 文字

画面のコードが文字を書くときの、テーマ変数の文字のユーティリティを、1 段ずつ見本と使う場面で並べる。

- 使う場面と規則、DADS のスタイルとの対応: `packages/ui/design/tokens.md` の「文字」
- 当たる原則: `packages/ui/DESIGN.md` の「画面を作るときの原則」の `TEXT-MIN-SIZE`、`COLOR-TOKEN`
- 値: `src/tokens/primitive.css` と `src/tokens/theme.css`
