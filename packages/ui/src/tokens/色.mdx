# 色

画面のコードが色を書くときのセマンティックトークンを、種類ごとに並べる。

- 使う場面: `packages/ui/design/tokens.md` の「色」
- テーマを切り替える条件: `packages/ui/design/tokens.md` の「テーマ」
- 当たる原則: `packages/ui/DESIGN.md` の「画面を作るときの原則」の `COLOR-TOKEN`、`STATE-NOT-COLOR-ONLY`
- 値: `src/tokens/semantic.css`（ライト）と `src/tokens/semantic-dark.css`（ダーク）
