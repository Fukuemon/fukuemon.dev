この記事は、シリーズ「このサイトの記事で使われる構成要素」の 4 本目である。
記事の中には、コードを読むだけでなく、その場で動かせる実行環境を置ける。
ここでは Node の実行環境を使って、何が動くかを説明する。

## 開いて動かす

次の枠のボタンを押すと、`index.js` と `package.json` を持つ実行環境が開く。
3000 番のポートでサーバーが動き、プレビューに結果が出る。

```playground
node-server
```

ボタンを押すまで、ブラウザは実行環境へのリクエストを送らない。
記事を読むだけの人には、実行環境の読み込みが掛からない。

## 複数のプロセスを動かす

実行環境は、複数のプロセスを同時に動かせる。
次の例は、モックの認可サーバー（4000 番）とクライアント（3000 番）を動かし、認可コードフローの通信を見せる。
プレビューで「認可サーバーでログインする」を押し、認可サーバーの画面で「許可する」を押すと、HTTP の一覧に 8 件のやり取りが起きた順に並ぶ。

```playground
oauth-code-flow
```

## 使えないもの

Node の実行環境を置く記事には、別の origin の画像や埋め込み（`img`、`iframe`、`video` など）を置けない。
実行環境を動かすために、記事に `COEP: require-corp` を返しており、ブラウザが別の origin のものを読み込まなくなるためである。
別の origin の画像を見せる例は、SQL の記事で説明する。

## 書く人向けの置き方

- 言語を `playground` にしたコードフェンスを置き、中に埋め込みの名前を 1 行で書く。
- プロジェクトは、記事の Markdown があるディレクトリの `playground/<埋め込みの名前>/` に置き、`playground.json` と初期ファイルを入れる。
- 埋め込みの名前は、英小文字、数字、ハイフンで書き、1 本の記事の中で重複させない。
