この記事は、Node の実行環境を埋め込む検証用の原稿である。
ボタンを押すと、`index.js` と `package.json` を持つ実行環境が開き、3000 番でサーバーが動く。

```playground
node-server
```

ボタンを押すまで、実行環境の通信は発生しない。
