# ADR-0043: キャンバスとスライドのエディタは、ツールごとに、名前を付けた複数の図とスライドを IndexedDB に保存する

## Status

提案

## Context

訪問者は、同じ端末で再訪したときに、前に描いた図と、前に作ったスライドを開ける。  
ツールごとに、図とスライドを 1 つだけ保存するか、複数保存するかを決める必要がある。

- 訪問者が作った図とスライドは、訪問者のブラウザに保存する。プレイグラウンドの中では、ツールの間で origin を分けない。
  - ADR-0031: [サブドメインに分ける規則を決め、1 つのアプリを 1 つの Worker とホスト名に割り当てる](0031-subdomains-and-workers.md)
- キャンバスは、draw.io の Embed Mode と Excalidraw の 2 つのツールである。draw.io の図は、親のページが受け取って保存する。
  - ADR-0039: [キャンバスは、構成図を draw.io の Embed Mode で、手描きの図を Excalidraw で、別のパスのツールとして提供する](0039-canvas-drawio-and-excalidraw.md)
- スライドのエディタは、Markdown を保存する。
  - ADR-0041: [スライドのエディタは Marp で作り、テーマの CSS からトークンの CSS 変数を参照する](0041-slides-editor-with-marp.md)
- 訪問者は、記事の図をキャンバスで開ける。
  - ADR-0040: [記事に埋め込むキャンバスの図は、元データ入りの SVG をリポジトリに置き、ビルドのときにインラインにする](0040-canvas-figures-in-articles.md)

## Decision

draw.io のツール、Excalidraw のツール、スライドのエディタは、どれも、名前を付けた複数の図かスライドを IndexedDB に保存する。  
訪問者は、一覧から、開く図かスライドを選ぶ。

- 「新しい図」と「新しいスライド」の操作は、前の図とスライドを消さない。
- 保存するデータの形を、3 つのツールでそろえる。

複数を保存する理由は、新しく作り始めたときに、訪問者が前に作ったものが消えないようにするためである。

## 承認の条件

- 訪問者が記事の図をキャンバスで開いたときに、開いた図を新しい図として保存するかを決める。

## Verification

端末、ブラウザ、バージョンは、ADR-0039 と ADR-0041 の Verification と同じである。  
試作は、ツールごとに図かスライドを 1 つだけ保存した。複数を保存する形は、試作していない。

- 3 つのツールで、編集のたびに IndexedDB に保存し、再訪で読み込めた（3 つのブラウザ）。
- 1 つだけ保存する draw.io のツールで、記事の図を開いて編集すると、保存してあった図が、開いた図に上書きされた（Chromium）。

## Considered Options

| 選択肢                                                           | 強み                                         | 弱み                                                                             |
| ---------------------------------------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------- |
| **採用:** ツールごとに、名前を付けた複数の図とスライドを保存する | 新しく作り始めても、前に作ったものが消えない | 一覧、名前の変更、削除の画面を作る。保存するデータの形に、名前と識別子が要る     |
| ツールごとに、図かスライドを 1 つだけ保存する                    | 作るものが少ない                             | 新しく作り始めると、前のものが消える。残したいものは、訪問者がファイルに保存する |

## Consequences

### Positive

- 訪問者は、複数の図とスライドを、同じ端末に残しておける。
- 3 つのツールで、保存と一覧の作りを共有できる。

### Negative

- 訪問者が保存した図とスライドが増えると、ブラウザの保存の容量を使う。
- 一覧と削除の画面を、ツールごとに置く。
