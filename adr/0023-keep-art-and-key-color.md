# ADR-0023: 個性として和の感じを残し、見出しを明朝にし、挿絵を作り替え、主の色を緑にする

## Status

承認（Decision の「主の色は、DADS の緑の階調にする」「角丸と影は、DADS の値を使う」と、「本文、等幅、版面は DADS に合わせる」の版面を ADR-0024 に置換）

## Context

DADS の仕組みでデザインを作り直すときに、今のデザインの個性として何を残すかを決める必要がある。

- 今のデザインの個性は、版画風の挿絵、明朝の書体（Zen Old Mincho と STIX Two Text）、緑と青と錆の差し色、角丸と影を使わない版面である。
- 運営者は、和の感じを残すと決めた。挿絵は作り替えてよく、フッターの草の図柄は要らない。書体は変えてよい。
- サイトの基盤の要求は、Lighthouse の Performance が 90 以上で、LCP が 2.5 秒以内であることを求める。
- DADS の書体は Noto Sans JP と Noto Sans Mono で、選んだ理由は可読性と視認性の高いサンセリフであることである。システムの書体を使うことは制限していない。
  - 出典: [DADS のタイポグラフィ](https://design.digital.go.jp/dads/foundations/typography/)
- DADS は、主の色を使う側が選ぶとしている。状態の色相（成功は緑、エラーは赤、注意は黄か橙）は変えないとしている。
  - 出典: [DADS の色](https://design.digital.go.jp/dads/foundations/color/)
- 和文の可変の書体は、1 つの分割がウェイトの軸を持つので重い。Noto Serif JP の可変は、1 つの分割が平均 56 KB だった。
  - ADR-0004: [和文に静的 2 ウェイトの Zen Old Mincho を採り、可変フォントを使わず self-host する](0004-typography-static-weights.md)
- 書体の大きさは、400 のウェイトの woff2 で、見出しに使う字だけ（約 400 字）に絞ったときの値である。google/fonts の TTF を pyftsubset で絞って測った。

## Decision

和の感じを、記事の題と見出しの明朝、作り替えた挿絵、主の色の 3 つで残す。本文、等幅、版面は DADS に合わせる。

- 書体
  - 本文は、Noto Sans JP の静的な 400 と 700 にする。Fontsource の unicode-range の分割を self-host で配る。
  - 記事の題と見出しは、Zen Old Mincho の 600 にする。ビルドで、見出しに使う字だけのファイルを作る（約 170 KB）。
  - 等幅は、Noto Sans Mono にする。和文の字は、等幅の和文の書体で受ける。どの書体で受けるかは、T2 で M PLUS 1 Code と BIZ UDGothic を比べて決める。
  - どの書体も `font-display: swap` にし、`size-adjust` で差し替えのずれを抑える。和文の分割は preload しない。
- 挿絵
  - 挿絵は、トークンの色で描く版画風の図柄に作り替える。フッターの草の図柄は置かない。
  - 挿絵は、トップ、記事の一覧の冒頭、about の帯にだけ置く。記事の本文とコードを動かす画面には置かない。
  - 挿絵の色は、セマンティックトークンの面と文字の色から作り、テーマごとに替える。
- 主の色は、DADS の緑の階調にする。
- 角丸と影は、DADS の値を使う。

## Considered Options

| 選択肢                                                                                     | 強み                                                                                                            | 弱み                                                                                                                            |
| ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **採用:** 見出しだけ明朝（Zen Old Mincho）、本文は Noto Sans JP                            | DADS から外れるのは見出しの書体だけである。本文の読み込みは DADS と同じ量で済む。見出しの字は約 170 KB          | 和の感じは、題と見出しと挿絵にしか出ない。見出しの字だけのファイルを作る処理を持つ                                              |
| BIZ UD の一族でそろえる（本文 BIZ UDPGothic、見出し BIZ UDPMincho 700、等幅 BIZ UDGothic） | 本文、見出し、等幅の字形がそろう。BIZ UDGothic は欧文が半角の等幅なので、エディタと端末で和文と欧文の幅がそろう | 和の感じは採用の案より弱い。本文の書体も DADS から外れる                                                                        |
| 本文も明朝（Zen Old Mincho と STIX Two Text）。今のデザインに近い                          | 和の感じが最も強い                                                                                              | 本文の書体が DADS から外れ、DADS がサンセリフを選んだ理由とも合わない。本文の字が多く、読み込む量が最も大きく、LCP が遅れやすい |

## Consequences

### Positive

- 本文の書体と読み込みの量が DADS と同じになり、DADS のコンポーネントの見た目をほぼそのまま使える。
- 記事の題と見出しで、今のサイトの明朝の印象が残る。

### Negative

- 見出しに使う字だけのファイルを作る処理（今の `apps/web/src/lib/subset-fonts.ts`）を、新しい構成に移す。記事が増えて見出しの字が増えると、ファイルが大きくなる。
- 挿絵の図柄を作り直す。
- 主の色の緑と成功の緑が並ぶ画面では、成功を文と印でも伝える。
- Noto Sans JP を静的にするか可変にするかは、Lighthouse で比べて決め直すことがある。
