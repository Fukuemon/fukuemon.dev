# ADR-0023: 個性として、挿絵と主の色を残す

## Status

提案

## Context

DADS の仕組みでデザインを作り直すときに、今のデザインの個性として何を残すかを決める必要がある。

- 今のデザインの個性は、版画風の挿絵、明朝の書体（Zen Old Mincho と STIX Two Text）、緑と青と錆の差し色、角丸と影を使わない版面である。
- デザインは DADS の仕組みで作り直し、個性は少し残す。
- サイトの基盤の要求は、Lighthouse の Performance が 90 以上で、LCP が 2.5 秒以内であることを求める。
- DADS は、主の色を使う側が選ぶとしている。状態の色相（成功は緑、エラーは赤、注意は黄か橙）は変えないとしている。
  - 出典: [DADS の色](https://design.digital.go.jp/dads/foundations/color/)

## Decision

挿絵と主の色を残し、書体と版面は DADS に合わせる。

- 挿絵は、トップ、記事の一覧の冒頭、about の帯にだけ置く。記事の本文とコードを動かす画面には置かない。
  - 挿絵の色は、セマンティックトークンの面と文字の色から作り、テーマごとに替える。
- 主の色に、DADS の緑の階調を当て、今の緑の差し色の印象を残す。
- 書体は、DADS の Noto Sans JP と Noto Sans Mono にする。
- 角丸と影は、DADS の値を使う。

## Considered Options

| 選択肢                                                       | 強み                                                   | 弱み                                                                                 |
| ------------------------------------------------------------ | ------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| **採用:** 挿絵と主の色を残す                                 | DADS から外れる点が増えない。読み込む書体が 2 つで済む | 明朝の本文の読み味は残らない。主の色と成功の色が同じ緑の色相になり、文と印で見分ける |
| 挿絵と主の色に加え、記事の題と見出しを Zen Old Mincho にする | 記事の画面に今の印象が残る                             | DADS の書体から外れる。和文の明朝を、使う字だけのファイルに作り直す処理を引き継ぐ    |
| 挿絵を残さず、主の色だけを残す                               | 挿絵の生成器（Python）と帯の規則を持たずに済む         | 今の個性がほとんど残らない                                                           |

## Consequences

### Positive

- DADS のコンポーネントの見た目を、ほぼそのまま使える。
- 書体のファイルが減り、記事の初回の表示が速くなる。

### Negative

- 挿絵の生成器と図柄の SVG を `packages/ui` に移し、トークンから色を作るように直す。
- 主の色の緑と成功の緑が並ぶ画面では、成功を文と印でも伝える。
