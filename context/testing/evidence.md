## Attachment

<!-- pull request への動作確認の動画の載せ方。次の手順をコマンドで書く。CLI のバージョンと上限の値は書かず、オプションがあるかを確認するコマンド（`--help`）と、上限を確認する公式の文書を書く
- 動画を 1 本上げるコマンドと、返る URL の取り出し方。上げるのに要る権限
- スレッドを立てるコマンド（最初のコメント）と、そのスレッドに返信を足すコマンド。返るスレッドの ID とコメントの ID の取り出し方
- スレッドの最初のコメントへのリンクの URL の作り方
- 投稿したコメントを、控えた ID で書き換えるコマンド
- pull request の本文をファイルに取るコマンドと、ファイルの本文で書き戻すコマンド。書き戻した本文を取り直して比べるときに、サービスが変える差（末尾の空白など）
- 本文で、動作確認の動画の節を足す見出しの行
- 1 つのファイル、コメント、本文の上限を確認する文書
- 上げた動画が表示されることの確認の方法。動画は、スレッドと本文の表の「エビデンス」の列のセルに `<details><summary><観点名> 改修後の動画</summary><video src="<URL>" controls muted></video></details>` の形で書くので、この形のセルが閉じて出て、開くと再生できることを確認する方法。本文とコメントの上げた先の URL の数え方
- 過去のコメントに付けた動画の URL を取り出す手順
- コメントに付けない理由のように、利用者のリポジトリが決めたこと
使う CLI の振る舞いのうち、リポジトリによらないもの（`gh` の `--attach` の参照の書き換え、失敗したときの終わり方など）は書かない。スキルの references が持つ -->
